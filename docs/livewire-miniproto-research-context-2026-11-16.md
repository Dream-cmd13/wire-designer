## 4. Livewire 已确认的功能

### 4.1 原理图与线束布局

- 顶部可切换 `Schematic` 与 `Harness`。
- Schematic 展示连接器 PIN 和逐根导线的连接。
- 在 Harness 的 Connector Table 中可以选择已有连接器，通过 `Place` 放入布局。
- 不需要从元件库重新创建另一组连接器来表达同一项目。
- `Auto Bundle` 在本次简单案例中生成一段包含两根导线的线束路径，并调整连接器位置和朝向。
- 线束段属性中可查看包含的导线，并通过 `Show in Wire Table` 筛选这些导线。

已确认的是此简单案例的关联，尚未验证复杂分支或所有修改的双向传播。

### 4.2 物料库及连接器关系

连接器详情包含三个标签页：

| 标签页 | 截图确认内容 |
| --- | --- |
| General | 料号、厂家/描述字段、孔位数、默认符号，以及 Datasheet、Octopart 链接入口 |
| Symbol and pinout | 通用符号视图、孔位编号及描述 |
| Compatible parts | 按孔位关联的端子、密封件、配对件、附件和替代件 |

`AT06-2S-ORG` 条目显示：

- 页头为 AMPHENOL、2 个孔位、Cadonix Public。
- 当前公共库条目只读。
- 通用符号包括向右、向左及双排平行等视图。
- 可选端子列表展示料号及线径范围，并标注适用孔位 1、2。
- 配对件列出 `AT04-2P-ORG`。
- 密封件、附件和替代件部分显示尚未录入。

必须区分：

- 通用原理符号不是实际连接器端面图。
- 配对件不是替代件，也不应自动作为当前线束的用料。
- 可选端子关系不是项目已选端子，不应把所有候选加入 BOM。
- 空列表表示当前未录入，不能解释为物理上不需要该类零件。

### 4.3 更换连接器与 PIN 映射

从 `0-326-52` 选择更换为 `AT06-2S-ORG` 时，弹窗明确提示两条导线按顺序映射并保留，提供：

- Cancel。
- Map manually。
- Replace。

早期截图中，更换后的料号已显示在画布上、导线对象仍可见，但后续 DRC 和 Wire Table 显示 C1 两端接线失效。

**不能据此直接判定替换功能存在 Bug**：尚未完整记录替换时的映射选择及中间操作。可以确认的是，导线图形仍在不等于端点数据仍有效。

**2026-11-17受控复核：** 在独立项目中执行同一对料号的默认Replace，两根线的From-To、Wire Table端点、Harness长度和BOM联动均保留。旧截图疑似接线失效未复现。替换后原理图仍提示缺少Gauge/Length，但表中物料与路径长度存在；不能据此断言替换丢失了这些属性，详见新报告。

### 4.4 三类表格及检查

| 功能 | 已确认内容 |
| --- | --- |
| Connector Table | 连接器汇总；Harness 中支持放置已有连接器；有导出入口 |
| From-To Table | 显示连接记录、起终点与状态；可选择、Auto Place、删除及导出 |
| Wire Table | 显示线号、料号、颜色、AWG/CSA、PIN 起终点与状态；有详细属性编辑区 |
| DRC | 显示错误、警告、提醒及 Refresh 按钮 |

From-To 记录曾使用 S2、S3，导线使用 W2、W3，尚未核实两类记录的确切对应模型。`Auto Place` 的完整行为也未验证，不能等同于自动修复接线。

Wire Table 中选择 W2 时，画布上的 W2 同时高亮，确认了选择联动。多选批量修改尚未实测。

### 4.5 线材规格

可见字段包括料号、描述、Gauge、CSA、颜色、Material、外径、Defined Length、Core Type。

选择 `0811-0272-BLAK` 后，截图显示：

- CSA：2 mm²。
- 颜色：BK，黑色。
- Material：PVC。
- 外径：0.110 in。
- AWG/CSA 列显示 `N/A (2)`。
- 状态点由黄色变为绿色。

这些显示支持“选料时带入规格”的观察；未验证字段锁定、任意覆盖或覆盖后与目录的校验规则。不能把绿色状态等同于全部制造检查通过。

### 4.6 长度与单位

线束段同时有：

- `Defined Length`：用户指定的长度。
- `Calculated Length`：系统根据布局计算的长度。

本次实验：

1. B01 最初 Calculated Length 显示 1.280 in。
2. 将 B01 Defined Length 设置为 10 in。
3. 画布同时显示指定长度和括号内计算长度，没有按指定长度自动等比例拉长布局。
4. 文档单位从 Imperial 切换为 Metric 后，指定长度显示 254.000 mm，计算长度曾显示 32.500 mm。
5. 部分后续截图计算长度显示 35.000 mm，最终截图又为 32.500 mm。中间操作未完整记录，不推断原因。
6. W1 的单根 Defined Length 输入框仍显示 0.000。
7. 图纸 Wire Table 和 PDF 中 W1、W2 的实际表列长度均为 254.000 mm。
8. DRC 明确提示两根导线的长度由 bundle route 计算。

可以确认：此案例中单根导线无需再手动填写指定长度，输出能够取得线束路径的 254 mm。不能认定该值已包含端子内部长度、裁切/剥皮余量或损耗。

### 4.7 保护层

Components 的 Coverings 分类中出现 Braid、Conduit、Spiral tape、Wrap、X Wrap 等占位件。

本次添加 Conduit 后：

- B01 属性中出现 `Conduit Closed (CVR-01)`。
- 画布显示导管纹理，B01 仍包含 W1、W2。
- 可展开保护层设置料号及两端偏移量。
- 将 `Offset from NODE 1` 从 0 改为 5 mm，导管在左侧 C1 一端缩进，NODE 2 保持 0。
- B01 指定长度保持 254 mm。

确认了这次布局中 NODE 1 对应 C1，且偏移影响覆盖图形。尚未证实保护层的物料长度是否按 `254 - 5 = 249 mm` 计算，也未验证其采用指定长度还是几何长度。

右侧卷状图标实际打开 `Other Parts`，该列表曾显示 0。它不是已确认的保护层用量表，不能用其空列表否定 CVR-01 已保存。

### 4.8 工程表格、图框与 PDF

左侧 Tables 提供可放入画布的 `Wire Table` 和 `BOM Table`。

另外，连接器可在图纸上显示端面视图和孔位表，孔位表包含：Cavity、Description、To、Wire ID、Wire PN、Color、AWG、Terminal PN、Seal PN、Plug PN。

Frames 支持：

- Landscape、Portrait。
- ISO A0～A4，以及 Legal、Letter、Tabloid。
- Custom frame 入口。

本次使用 A4 横向。Frame properties 显示 ISO、A4、Landscape，宽高 297 × 210 mm 为只读，面板中未见比例字段。不能据此断言整个产品不存在其他比例功能；自定义图框也未实测。

顶部 Share 菜单包含：

- Share with people。
- Export entire drawing as PDF。
- Export Frames as PDF。

已实际试用的是 `Export Frames as PDF`。截图中的结果为单页，保留图框、标题栏和框内内容，未显示编辑网格或选中框。没有自动把偏小的线束放大铺满纸张。

最终 PDF 截图包含：线束结构、C1 端面图、C1 孔位表、Wire Table、BOM Table、标题栏。内容总体仍偏小、留白较多，属于当前示例排版，不能据此判定产品缺少排版能力。

1. `0-326-52` 的物料属性是 DURITE、2 孔，但 AI Summary 描述 3M、26 位 D-Sub 后壳，内容明显不一致，根因未知。

5. 先前线材候选包括 35 mm² 等大截面物料；尚未证实候选列表按连接器或端子线径适配筛选。

以上属于具体可见现象，不能推广为整个产品全部物料或所有流程的问题。

完整测试步骤、数值、待验证边界及截图见[MiniProto 浏览器实测与 Livewire 对比分析](research/miniproto-2026-11-16/report.md)。

## 8. 对当前系统的优化建议

以下是建议方向，尚未转换为批准的实施范围和验收任务。

### 8.1 优先复用现有基础

1. **设计检查可见化**：复用校验引擎，展示问题列表、定位对象，并区分草稿保存和正式输出要求。
2. **接线表与画布联动**：同一接线数据支持集中编辑、选择定位及工程表格生成。
3. **连接器替换校验**：预览 PIN 映射，明确保留、失效和需处理的接线，替换后重新校验并支持撤销。
4. **减少重复录入**：先做固定模板的 Excel From-To 导入；多芯线必须保留所属护套线和芯线编号，避免错误计料。
5. **报价与人工交接**：保留现有快速报价；超出范围时生成包含配置、接线、BOM、数量、图纸和原因的待人工核价资料。
6. **输出资料完整性与排版**：提示占位件、缺失图形、必要规格及表格放置问题，提供清晰预览。

### 8.2 需要先确认业务规则的方向

- 多根导线共用线束段、分支路径和接续点的建模需求。
- 指定长度、几何长度、导线裁切长度、端部余量、损耗的计算关系。
- 保护层覆盖范围、两端预留和实际用量；导线按根/长度、保护层按件/长度等单位规则。
- 项目到独立图纸先实现可靠的单向生成、记录来源及更新提示；完整双向编辑成本更高。
- 已保存报价的配置关联、规则版本、历史结果与重新核价结果的区分。

### 8.3 后置或按需投入

- 壳体、孔位、端子、密封件的完整适配模型：实际分体连接器业务需要后再投入。
- AI 优先用于真实目录检索与需求解析，结果必须能追溯到料号和资料。
- 不优先建设复杂团队协作、完整支付订单系统、三维自动布线或大范围架构重构。

所有结构调整必须保留现有项目、图纸和物料数据；真实物料单位与价格规则变化需要核对现有核价口径，不能沿用竞品默认规则。
