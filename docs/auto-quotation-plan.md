# 自动报价独立功能方案

日期：2026-10-09
状态：方案确认记录，尚未实施

## 1. 目标与已确认决策

在现有系统导航中新增「自动报价」Tab。业务人员选择 A/B 端、模具、线材并填写长度与数量，系统展示对应报价和图纸预览。

- 独立页面、独立业务数据，与现有设计器工程及物料库数据分开。
- 只新增一张业务表 `auto_quote_materials`，后续单独补充物料、价格和绘图资料。
- 复用当前设计器的实时报价公式，不新增加工规则表、不复制另一套报价公式。
- 共用现有登录、导航、基础 UI 和可复用的绘图能力，无需另建应用或数据库。
- 首版聚焦一根实体线材、单头或双头的配置场景，不扩展多分支线束。
- 暂不补齐「剥皮沾锡计费」和「TPE 外模、PE 内模材料计价」两项能力，后续单独实施。

## 2. 当前系统报价来源

### 2.1 设计器实时报价

`src/lib/pricing.ts` 中的 `calculatePrice` 根据配置与物料价格实时核算。`src/lib/quoteExport.ts` 的 Excel 导出调用同一计算函数，不是另一套公式。

现有工艺计算如下，金额单位为元：

| 工序 | 当前计算方式 |
| --- | --- |
| 裁线 | 向上取整（长度 mm / 500）× 0.05 |
| 去皮 | 芯数 × 加工端数 × 0.02 |
| 去外皮 | 加工端数 × 0.02 |
| 处理编织 | 屏蔽线加工端数 × 0.10 |
| 热缩编织 | 屏蔽线加工端数 × 0.10 |
| 焊接 |（芯数 + 屏蔽附加点）× 加工端数 × 0.20 |
| 成型 |（外模数 + 内模数 + SR 点数）× 0.20 |
| 电测 | 每件 0.05 |
| 外观 | 每件 0.20 |
| 包装人工 | 每件 0.20 |

屏蔽线的屏蔽附加点为 1，非屏蔽线为 0。当前加工端数与连接器数量一致。

```text
材料损耗 = 材料费 × 3%
加工损耗 = 加工费 × 5%
成本 = 材料费 + 加工费 + 材料损耗 + 加工损耗
售价 = 成本 ÷ 0.8
运费 = 售价 × 3%
单价 = 售价 + 运费，四舍五入到两位小数
总价 = 已舍入单价 × 数量
```

材料价格采用含税价格；运费的 3% 不是税率。复用现有 Decimal 精度与舍入方式。

### 2.2 成品物料库成本分析

`scripts/import-cost-analyses.mjs` 从 Excel 原表读取成本、价格、公式与计算过程，再保存供页面展示。各产品的源表公式可能不同，正式报价也可能来自人工审核或供应商。

因此系统存在两种报价来源，但只有第一种是本方案直接复用的通用在线计算入口。本功能不根据成品物料库历史 Excel 公式重新计算。

## 3. 页面与交互

建议路由为 `/auto-quote`，在主导航增加「自动报价」。沿用现有登录访问机制。

页面左侧填写配置，右侧显示报价摘要与图纸预览；较窄屏幕改为上下排列。数据维护入口可放在本模块内，以列表和编辑弹窗实现，不新增复杂的管理系统。

| 字段 | 控件与行为 |
| --- | --- |
| A 端连接器 | 根据料号、名称搜索，选择后带出规格与图片 |
| B 端形式 | 单选：连接器、切断、剥皮沾锡 |
| B 端连接器 | 仅 B 端为连接器时显示并必填 |
| 外模 | PVC 45P、TPE；按连接器适配关系选择具体物料 |
| 内模 | PE、无 |
| 线材 | 搜索选择，带出芯数、线径、外径、屏蔽等属性 |
| 长度 | 正数输入，内部统一使用整数 mm |
| 数量 | 正整数，用于计算订单总价 |

切断按裸端平切理解，不自动添加剥皮和沾锡。单连接器场景默认仅在连接器端配置模具，双头默认两端采用相同模具选项；无法唯一确定具体模具时，应提示选择，不能任取一个。

首版将尚未支持的剥皮沾锡、TPE、PE 选项显示为「待支持」并禁用。这样保留目标字段，不会将未计入的费用当作完整报价。后续补齐能力后再启用，不默认替换成其他工艺或材料。

输入完整后自动核算；修改配置后同步更新价格与预览。输入不完整、缺价或规则不支持时，清除或明确作废旧报价，不保留容易误认的旧金额。

## 4. 单表设计

表名：`auto_quote_materials`。一行代表一个可选物料，四类物料共用一张表。

| 字段 | 建议类型 | 用途 |
| --- | --- | --- |
| `id` | UUID，主键 | 稳定标识 |
| `category` | text | connector / wire / outer_mold / inner_mold |
| `part_no` | text | 料号 |
| `name` | text | 物料名称 |
| `spec` | JSONB | 按类型保存针数、系列、芯数、材质、硬度等属性 |
| `pricing` | JSONB | 含税价格、计价单位、线材长度档位 |
| `drawing_data` | JSONB | 图片引用、尺寸、绘图参数、必要的配套信息 |
| `enabled` | boolean | 是否可选 |
| `created_at` | timestamptz | 创建时间 |
| `updated_at` | timestamptz | 更新时间 |

约束与约定：

- `category + part_no` 唯一；料号保存前去除首尾空格。
- 各 JSONB 字段使用明确的 TypeScript 类型及保存校验，不作为任意数据容器。
- 未维护价格用缺失值或 null 表示，不能自动填成 0。
- 金额建议使用十进制字符串，进入现有 Decimal 运算。
- 连接器和模具按件计价，线材保留现有「长度档位、元/条」口径。
- 线材取不小于实际长度的最小有效档位；没有适用档位时待核价，不改用米价推算。
- 图片存已有文件存储，表内仅存引用，不把大图片二进制塞入 JSONB。
- 不引用旧物料库业务记录；新表的稳定 ID 用于报价材料身份匹配。
- 访问权限沿用项目现有身份体系，读取和维护权限需在数据库端落实，不能只隐藏按钮。

首版不增加报价历史表，也不将历史记录混入物料表。当前配置保存在页面独立状态中，支持预览和导出；离开或刷新页面后是否保留草稿不作为首版验收要求。

## 5. 复用公式与数据流

```text
独立物料表 → 自动报价页面配置
                     ├→ 配置适配 → 现有 calculatePrice → 报价摘要与明细
                     └→ 绘图适配 → 图纸预览与导出
```

通过一个小型适配层，将新表物料转换成现有计算入口所需的配置、目录和价格结构。计算函数使用本次配置对应的数据，不从现有设计器的全局工程状态读取或回写。

优先保留 `calculatePrice` 的现有业务规则。只有必要时调整输入边界，不重写或复制工艺金额、比例及舍入公式。

首版继续遵守当前计算边界：

- 一根实体线材，1～2 个连接器。
- 连接器限现有公式支持的 M8、M12。
- 外模限黑色 PVC 45P。
- 长度超过 5000mm 转人工核价。
- 数量范围为 1～1000000 的整数；长度与芯数等沿用现有校验。
- 缺少唯一匹配价格、价格无效、数据不完整时不输出完整报价。

数据维护入口可以录入未来使用的物料，但录入不代表当前报价公式已支持该物料。

## 6. 图纸范围

首版图纸定义为「报价确认图／结构示意图」，显示 A/B 端、线材规格、长度及其定义、模具说明和端部形式。

复用现有绘图组件或 `src/lib/drawingGenerator.ts` 中适用的生成能力，新增必要的配置适配；不能假定现有生成器已覆盖所有新组合。

- 没有已确认接线资料时，不推断针位映射或默认同针直连。
- 缺少剥皮尺寸、公差、线序等生产信息时，不标记为可直接生产的图纸。
- 缺少图片时可显示明确的简化结构示意，不伪造物料外观。
- 价格与图纸来自同一份当前配置，避免参数不一致。
- 首版目标为页面预览、报价 Excel 和图纸 PDF 导出；原生 DWG 生成不在范围内。
- 对客报价与内部成本明细明确区分，避免将成本拆解误作为客户报价单。

长度是成品总长还是裁线长、具体测量基准，实施前仍需业务确认；确认前不能将示意长度当作生产尺寸。

## 7. 暂缓项

用户已明确以下两项后续补齐，本次不新增其公式或计费行为：

1. **剥皮沾锡**：不新增独立沾锡计费，不调整加工端数与连接器数量的关系，不默认把沾锡等同于焊接。
2. **TPE 外模及 PE 内模材料计价**：不放开现有 PVC 45P 限制，不将当前内模材料零值处理视为 PE 免费。

这意味着首版目标字段保留，但完整自动报价只对当前公式实际支持的组合开放。两项暂缓能力不列入首版通过条件。

## 8. 数据补充与实施顺序

1. 新增单表、类型、访问控制和数据读写入口。
2. 新增独立 Tab、配置表单和本模块物料维护入口。
3. 将新表数据适配至现有计算函数，展示单价、总价与明细。
4. 接入结构图预览与导出，确保不影响当前设计器工程。
5. 用明确标记的测试资料验证支持范围，再由业务补充实际料号、价格和绘图参数。

实际数据可以后补。空表显示维护引导；缺价显示具体缺项；接口失败显示可重试错误，不使用演示价或过期结果冒充当前正式报价。

## 9. 验收标准与验证

- 导航可进入独立页面，刷新路由与登录访问正常。
- 仅新增一张业务表，新增物料不写入旧物料库。
- 可维护、选择已支持的物料，A/B 端条件字段切换正确。
- 同配置、同价格下，新页面和原计算函数的明细及金额一致。
- 覆盖单头、双头、屏蔽线、长度档位边界、超过 5 米、缺价与非法输入。
- 剥皮沾锡、TPE、PE 显示待支持，不生成遗漏费用的正式报价。
- 改变配置后，金额、图纸和导出内容一致；无效配置不会继续显示有效旧报价。
- 空数据、加载失败及绘图资料不足均有清晰状态。
- 自动报价操作不会覆盖设计器中正在编辑的工程。
- 后续实施时，对修改代码执行 ESLint（0 错误、0 告警）、`npx tsc -b` 及受影响的 `npm test` 测试集，并完成页面功能走查。

本文件为方案文档；本轮未实施数据库、页面或计算逻辑变更，未执行功能测试。
