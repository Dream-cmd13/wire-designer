# 自动报价方案（零新表）

> 历史规划：2026-10-12 已支持 PE 内模与 B 端剥皮沾锡，去皮 0.05 元/点、沾锡 0.05 元/点，SR 不计费；当前计费以 [报价业务规则](报价业务规则.md) 为准。

日期：2026-10-09
状态：待实施方案；本方案替代 `docs/auto-quotation-plan.md` 中的「新增单表」方案，原文件保留作历史备选。

## 一、目标与边界

在首页导航新增独立的「自动报价」Tab。业务人员选择 A 端连接器、B 端形式、外模、内模、线材，填写长度和订单数量后，查看价格与图纸预览。页面独立，但物料和价格与现有设计器共用；不新增数据库表，不建立第二套价格库或加工费公式。

首版仅对当前实时报价函数实际支持的组合给出正式金额。剥皮沾锡、TPE 外模和 PE 内模的计费留待后续补齐；页面可展示这些目标选项及「待支持」状态，但不能给出漏算费用的正式报价。

## 二、现有数据如何使用

| 现有来源 | 当前能力 | 本功能用途 |
| --- | --- | --- |
| `catalog_items` | 连接器、线材、外模的料号/型号、规格、图片路径 | 搜索和选择物料、带出图纸所需的已知属性 |
| `material_prices` | 与 `catalog_items.id` 关联的含税价格；线材按长度档位存价 | 报价材料单价与缺价判断 |
| `src/lib/pricing.ts` | `calculatePrice` 实时计算加工费、损耗、售价和运费 | 唯一的在线报价计算入口 |
| 现有绘图模型与组件 | 图纸对象、预览与导出基础能力 | 生成报价确认图；缺失的接线信息不自动推断 |

后续新增料号直接维护到现有物料目录，价格维护到现有价格表。先建档后补价可以，但缺价时只显示「待核价」。`material_prices` 目前仅支持连接器、线材、外模三类；PE 内模不能通过现有价格表作为独立材料正常计价。

**数据共享的影响：**新页面与设计器引用同一物料和价格。维护人员修改共享价格，后续两处报价都会使用新价格。因此页面独立不等于数据独立。首版不保存报价历史；如果后续需要锁定历史报价，再单独设计快照，不能让历史金额随价格表变动。

## 三、页面设计

建议路由 `/auto-quote`，沿用现有登录与导航机制。桌面端左侧填写、右侧显示报价和图纸；窄屏上下排列。业务输入如下：

| 字段 | 输入方式与规则 |
| --- | --- |
| A 端连接器料号 | 从 `catalog_items` 中搜索选择，带出名称、针数和图片 |
| B 端形式 | 单选「连接器 / 切断 / 剥皮沾锡」；仅选连接器时填写 B 端料号 |
| 外模 | 从目录中选择适用的黑色 PVC 45P；TPE 标记待支持 |
| 内模 | 「无 / PE」；首版 PE 标记待支持 |
| 线材 | 从目录中选择，显示芯数、规格、屏蔽属性等 |
| 长度 | 正整数 mm，显示清楚是报价所用线长 |
| 订单数量 | 1 至 1000000 的整数 |

当 B 端为「切断」时，首版按一个连接器、一个加工端配置，不对切断端额外计费。剥皮沾锡不套用当前焊接价格。模具是否适配连接器与线材，若目录信息不足以判断，则要求业务明确选择并在预览中标示所选料号，不猜测型号。

输入变化时，同步重算价格和更新图纸；加载中、缺价、条件不支持或请求失败时，清除旧的有效金额并给出具体原因。不能以 0 元、上一次结果或演示价代替正式报价。

## 四、公式复用与首版可报价范围

新页面使用独立的临时表单状态，将已选目录物料、价格与工艺参数适配成 `calculatePrice` 的输入。不得读写当前设计器工程状态，也不在页面内重写加工费、损耗、毛利和运费公式。报价 Excel 如需导出，应从同一份计算结果生成，确保页面金额与导出金额一致。

当前公式适用条件：

- 一根实体线材、1～2 个 M8/M12 连接器；加工端数必须等于连接器数量。
- 外模仅支持目录中的黑色 PVC 45P；外模数量不大于加工端数。
- 线材价格取不小于实际长度的最小有效档位；缺少唯一匹配档位时待核价。
- 线长超过 5000mm 转人工核价。
- 内模的成型工费虽进入现有公式，但内模材料费当前为零，不能据此把 PE 视为免费。
- 材料损耗 3%、加工损耗 5%、成本除以 0.8 计算售价、售价的 3% 为运费；沿用现有 Decimal 舍入方式。

`src/lib/quoteExport.ts` 调用上述同一个计算函数；成品物料库显示的是从历史 Excel 导入的成本分析，不是第二套可直接复用的在线计算引擎。

首版正式报价支持的典型组合是「A 端连接器 + B 端切断」或「A/B 双端连接器」，配一根线材，外模为无或当前支持的黑色 PVC 45P，内模为无，并满足上述价格和长度条件。是否允许不装外模，按现有公式对空模具列表的支持实施。

## 五、图纸与导出

首版产物是**报价确认图/结构示意图**，与当前价格使用同一份配置，显示 A/B 端、所选料号、线材规格、长度、外模和端部形式。可复用现有图纸生成与预览能力，但应先核实其对单头、双头及未定义线序的实际表现。

没有针位对应、芯线颜色、剥皮尺寸、公差和长度测量基准时，不自动推断，不标记为可直接生产的图纸。图片缺失时使用明确的简化示意。首版可规划报价 Excel 与图纸 PDF 导出；原生 DWG 生成不纳入本方案。若选择保存图纸，可使用现有 `drawings` 表，但首版不要求保存报价或图纸记录。

## 六、实施步骤

1. 在现有路由与主导航增加「自动报价」页面，沿用身份检查。
2. 使用现有目录与价格读取能力建立搜索选择；按当前公式能力筛选或禁用待支持选项。
3. 增加页面配置到 `calculatePrice` 输入的适配，展示单价、总价、加工与材料明细、缺价/人工核价原因。
4. 接入图纸预览和导出，保持图纸、页面金额及报价 Excel 的配置一致。
5. 使用现有物料维护流程补充测试料号和有效价格；实际业务数据后续逐步录入，无需新表迁移。

如现有目录没有合适料号、价格或图纸资料，先显示空状态和维护指引，不写入假数据。只为页面需要调整现有查询或类型；不改动旧表结构，不新增 SQL 表。

## 七、验收与待确认事项

验收重点：零新表；独立路由正常；单头/双头支持组合可报价且金额与现有函数一致；缺价、超过 5 米与待支持选项不生成正式金额；修改输入后报价和示意图同步更新；不覆盖设计器当前工程。实施后运行改动文件 ESLint、`npx tsc -b`、受影响的 `npm test`，并完成页面走查。

实施前需确认长度指**成品总长还是裁线长**及其测量基准。若未确认，只能用于报价估算，不能将预览中的长度标作生产尺寸。另需决定报价 Excel 是否包含内部成本明细；对客报价不应默认暴露成本和毛利。

后续任务：补齐剥皮沾锡工艺、TPE 外模、PE 内模材料计价后，再开放对应选项的正式自动报价。这些内容不属于首版验收范围。
