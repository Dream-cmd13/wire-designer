## 替换记录

本次操作前的完整物料备份、源表摘要、删除清单和价格冲突明细位于 `.tmp/real-catalog-FSOwMm/`，属于本机备份，不纳入 Git。

`scripts/prepare-real-catalog.mjs` 使用只读数据库查询准备备份及计划。
`scripts/apply-real-catalog.mjs` 为本次固定范围替换脚本，校验备份与当前数据库一致，默认事务试跑后回滚，`--apply` 提交。
脚本使用 `.env` 中的服务端凭证及 PostgreSQL 连接参数，数据库驱动安装在 `.tmp/db-runtime`。重新执行需先生成新备份；已完成替换后不会再次接受原 46 条删除计划。

本次数据库变更在同一事务内更新线材约束、导入物料并删除已核实记录。未修改项目文档、用户数据或 Storage 图片文件。引用已删除展示物料的旧项目需要重新选用真实物料。
