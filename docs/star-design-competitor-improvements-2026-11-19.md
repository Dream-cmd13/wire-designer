# 星设计改进建议

2026 年 11 月 19 日。结合 Livewire CAD、MiniProto 的实测与 REA 调研，以及星设计 `dev` 分支源码核查。

**首批建议做换料影响预览、校验定位和项目级接线总表。** 优先处理换料，因为缩减针位时，当前界面会直接应用变更，底层返回的断线警告没有展示给用户。三项均可复用现有的连接器、线材和回路数据。 [竞品调研报告](livewire-miniproto-rea-report-2026-11-19.md) · [星设计换料入口](../src/components/canvas/HarnessCanvas.tsx#L1766)

| 优先级 | 改进项 | 希望解决的问题 |
| --- | --- | --- |
| P0 | 换料前预览 PIN 映射 | 避免换型后才发现针脚引用或跳线被移除 |
| P0 | 实时校验与问题定位 | 将缺项、越界和冲突定位到具体元件、针脚或回路 |
| P1 | 项目级 From-To 接线总表 | 集中核对全项目接线，减少在画布和各线材明细之间切换 |
| P1 | 展示设计长度、备料用量和损耗金额 | 让工程、采购和报价人员使用明确的计量口径 |
| P2 | 项目报价留档与对比 | 找回过去的报价，追溯数量、工艺、配置或定价变化 |

## P0 换料前预览 PIN 映射

Livewire 实测中，同针数换型保留了已布线端点。星设计当前也保留新型号针数范围内的接线，但会清理越界端点和跳线针脚，并移除不足两个端点的跳线。换料命令返回接线警告，画布直接应用了新配置。 [Livewire 实测记录](research/livewire-2026-11-17/report.md) · [换料命令](../src/lib/commands.ts#L129) · [画布换料入口](../src/components/canvas/HarnessCanvas.tsx#L1766)

换料确认页应列出保留、需重新映射和将断开的接线或跳线。验收可用一个接有第 5 针的 5 针连接器换成 4 针连接器。确认前能看清受影响的回路并选定目标针或明确断开，取消后原接线保持原样，确认后核对接线图和 BOM。

## P0 实时校验与问题定位

MiniProto 会在问题面板列出缺失的 `W3S` 锁片并提供补选入口。星设计的 `validateHarness` 已覆盖缺型号、针脚引用、接线侧冲突等规则，目前可在设计文件流程找到调用。可复用这些规则，在画布汇总错误和警告，并把问题条目连到具体对象的属性或接线明细。 [竞品调研报告](livewire-miniproto-rea-report-2026-11-19.md#miniproto) · [校验规则](../src/lib/validation.ts#L12) · [设计文件校验](../src/lib/designFile.ts#L22)

验收时打开含问题的样例项目，从列表定位对象，修正后确认对应条目消失。区分草稿保存和生产导出的检查要求，只有已明确影响交付的错误才阻止生产导出。

## P1 项目级 From-To 接线总表

Livewire 的 DEMO 实际导出了 50 条 From-To 记录。MiniProto 的 Wires 面板集中展示端点、线径、颜色和长度。星设计已有按线材查看和编辑的回路明细，成品图也从项目数据生成接线图。可以基于同一组回路数据提供项目总表，首版支持筛选、定位和 CSV 导出，随后再增加改针和固定模板批量导入。 [竞品调研报告](livewire-miniproto-rea-report-2026-11-19.md) · [画布接线明细](../src/components/canvas/WireMaterialNode.tsx#L163) · [成品图接线图](../src/components/drawings/TwoDView.tsx#L64)

验收用一个含两种线材的项目，对照总表、画布和导出的端点。加入表格编辑后，验证从表里改一个针位，画布、成品图和导出均显示相同结果。

## P1 长度、备料和损耗口径

MiniProto 的独立导线 BOM 用量由设计长度和可配置的损耗系数计算，实测配置为 15%。星设计已有材料与加工损耗金额。可以先在 BOM 和报价界面明确设计长度、备料用量与损耗各自的单位、计算来源和适用范围。如果采购需要按含余量的长度备料，再由实际线材和工艺规则确定系数。 [竞品导线用量](livewire-miniproto-rea-report-2026-11-19.md#miniproto) · [星设计成本计算](../server/pricing.ts#L109)

验收可用同一根导线对照成品图标注、备料数量和成本明细。确认备料余量是否已经纳入材料金额，再确定同一因素在报价中只计一次。

## P2 项目报价留档与对比

星设计已有服务端核价和 Excel 报价导出，返回值包含核价时间与定价设置版本。若业务经常需要找回旧价，可在项目里按需保存报价当时的配置、数量、工艺、核价时间、定价设置版本和金额，并提供历史记录与方案对比。 [服务端报价结果](../src/lib/pricing.ts#L10) · [Excel 导出](../src/lib/quoteExport.ts#L23)

验收可先按同一设计保存两种数量的报价，再更新定价并重新核价。历史记录应仍可按原金额查看与导出，至少能核对两次的配置、数量和规则版本差异。

## 后续评估

自动成束应先用含护套、固定长度和手工布置的样例验证其影响。原理图与线束双视图可在项目级接线数据和校验流程稳定后，按实际的电气设计需求决定。对外 API 可等出现明确的询价或生产集成需求后，再评估复用现有的校验和报价入口。 [竞品调研报告](livewire-miniproto-rea-report-2026-11-19.md)
