# 独立制作图纸、刷新确认与默认表格保留设计

## 目标

“制作图纸”是独立制图工具，不关联当前线束项目。用户每次从默认图纸开始制作并导出 PDF；在同一次应用运行期间切换模块不会丢失当前画布；浏览器刷新后由用户决定继续旧图纸还是丢弃并重新生成默认三表格。

## 范围

- 仅修改“制作图纸”模块。
- 不读写项目配置，不改变线束设计器、项目管理或线束库的数据。
- 保留现有绘图、物料表、PDF 导出、撤销重做和对象交互能力。
- 不迁移或覆盖用户旧图纸，除非用户在刷新确认 toast 中明确选择丢弃。

## 页面生命周期

### 首次进入且没有本地草稿

等待独立绘图 store 完成持久化恢复。如果不存在有效活动图纸，创建一张新图纸。新图纸必须包含：

1. 左下角物料表。
2. 右上角版本变更表。
3. 右下角标题栏表格。

隐藏的文档标题元数据对象可以继续存在，但不计入三张可见默认表格。

### 同一次应用运行期间切换模块

离开“制作图纸”再返回时复用当前独立画布：

- 不显示刷新确认。
- 不重新创建图纸。
- 不丢失对象、选择之外的绘图数据或物料数据。

### 浏览器刷新

模块运行时状态在刷新后重新初始化，但独立绘图草稿仍由本地持久化恢复。

- 若恢复到旧活动图纸，显示带两个操作按钮的 toast：
  - “继续制作”：关闭 toast，保留恢复的旧图纸。
  - “丢弃并新建”：删除独立绘图草稿并创建一张新的默认三表格图纸。
- 无论旧图纸是否成功导出过 PDF，都显示该确认。
- 若没有旧图纸，则不显示确认，直接创建新图纸。
- 在用户作出选择前不创建额外图纸，也不修改恢复的旧图纸。

为区分“模块切换”和“浏览器刷新”，使用仅在当前 JavaScript 运行时存活的模块级会话标记。路由切换不会重置该标记，浏览器刷新会重置。页面必须等待 Zustand persist hydration 完成后再判断是否存在旧图纸，避免初始化与恢复之间的竞态。

## 清空画布

“清空画布”不是删除所有对象，而是将当前图纸恢复为同尺寸的新建基础模板：

- 删除用户添加的直线、折线、曲线、自由画笔、文字、标签、标注、连接器、线束、附件、自定义表格、图标和其他非默认对象。
- 重新生成左下物料表、右上版本表、右下标题栏表格。
- 默认表格恢复到新建状态；物料行、用户编辑过的单元格、缩放、移动、锁定和样式修改都不保留。
- 保留当前文档 ID、名称、创建时间和页面配置，以便撤销历史仍将其视为同一文档。
- 更新文档时间，并清除当前选择、局部编辑弹窗和上下文菜单。
- 清空操作产生一个可撤销快照；已经处于默认基础模板时重复清空不新增历史。

默认基础对象不通过易变化的显示文本识别，而通过稳定的 tableRole 和隐藏标题对象类型识别。重建基础模板时复用 createBlankDrawingDocument，避免初始化和清空逻辑产生两套默认值。

## 与项目界面的隔离

制作图纸内容始终来自独立绘图 store。页面标题区域在该路由下显示“独立制图 · 新建后导出”，不显示当前项目名称，也不显示关闭项目操作。其他模块仍保持现有项目标题和操作。

## 状态重置

用户选择“丢弃并新建”后，除新图纸外还要清理：

- 撤销与重做历史。
- 当前选择。
- 剪贴板。
- 右键菜单。
- 线属性、物料表、表格创建、资源和导出相关弹窗状态。
- 当前绘图工具恢复为选择模式。

用户选择“继续制作”时不修改这些持久化绘图数据。

## 错误与提示

- 刷新确认使用中文 toast，不使用浏览器原生确认框。
- toast 文案为“是否丢弃当前制作的图纸？”。
- 操作为“继续制作”和“丢弃并新建”。
- 不暴露本地存储或数据库英文错误。

## 测试

### 纯函数测试

- 新建文档包含且仅包含三张可见默认表格。
- 清空含额外对象、已编辑物料表和已移动标题栏的图纸后，得到新的默认三表格。
- 清空保持文档 ID、名称、创建时间和页面配置。
- 默认状态重复清空返回原对象，不产生无效历史。

### Store 与页面测试

- 独立绘图 store 提供原子化的“替换为新图纸”操作，不触碰项目 store。
- 页面等待持久化 hydration 后初始化。
- 当前运行时第一次从本地恢复旧图纸时显示刷新确认。
- 同一运行时模块切换后重新挂载不显示确认，继续当前画布。
- “丢弃并新建”调用独立 store 重置并清理页面临时状态。
- “继续制作”保留恢复图纸。
- 制作图纸路由不展示当前项目名称和关闭项目操作。

### 验收

1. 首次打开制作图纸，看到默认三表格。
2. 添加对象后切换到其他模块再返回，对象仍存在且没有确认提示。
3. 刷新浏览器，看到确认 toast。
4. 选择继续制作，旧内容保留。
5. 再次刷新并选择丢弃，新画布只包含默认三表格。
6. 添加对象并修改默认表格后点击清空，其他对象被删除，三张表格恢复默认状态。
7. 导出 PDF 后刷新，仍显示确认 toast。
