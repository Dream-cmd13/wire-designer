# 整表拖拽与局部选择交互设计

## 目标

让表格的整表移动与单元格、文字局部操作具有明确的状态优先级，避免表格内部元素截获整表拖拽。

## 交互规则

1. 框选区域完整覆盖表格，或单击表格边缘时，选择整张表格并显示整表八个控制手柄。
2. 整表处于八手柄选中状态时，从表格任意位置按住左键拖动均移动整张表格。
3. 整表选中时，双击单元格或文字只切换到对应的局部目标，并显示局部八个控制手柄，不立即编辑文字。
4. 文字已经是当前局部目标时，再次双击同一段文字才进入文字编辑。
5. 双击不同单元格或文字时，只切换局部目标，不立即编辑。
6. 局部目标选中后保留现有局部缩放、单元格尺寸调整和文字拖动能力。
7. 单击表格边缘或重新框选整表会清除局部目标，恢复整表选择状态。

## 实现边界

- 沿用现有 `tableTarget === null` 表示整表选择、非空表示局部选择的状态模型。
- 在表格 DOM 层根据当前选择状态统一决定指针事件归属，不改变绘图对象数据结构。
- 不修改其他图形对象的选择、缩放和拖拽行为。
- 不引入新的快捷键或工具栏按钮。

## 事件流程

- 整表状态：内部元素的左键拖动交给整表移动；内部元素首次双击设置局部目标。
- 局部状态：已有的局部拖动和控制手柄继续工作；同一文字的双击进入编辑。
- 框选完成：若表格被完整覆盖，选择该表格并清除它的局部目标。

## 测试与验收

- 框选完整覆盖表格后出现整表八个手柄。
- 单击边缘后出现整表八个手柄。
- 整表选中时，从标题、表头、单元格或文字区域拖动都会整体移动表格。
- 整表选中时首次双击文字只显示文字局部八个手柄。
- 再次双击同一文字进入编辑。
- 双击不同目标只切换局部八手柄。
- 局部缩放、单元格调整、文字拖动及其他画布对象交互没有回归。
