# 制作图纸画布右键菜单与路径裁剪设计

## 目标

在制作图纸画布内拦截浏览器默认右键菜单，提供符合绘图场景的自定义菜单。画布空白处提供粘贴；实体上提供复制、删除、裁剪、图层调整和锁定操作。

## 范围

- 只替换制作图纸画布区域的浏览器右键菜单。
- 空白画布菜单只显示“粘贴”。
- 实体菜单显示“复制、删除、裁剪、移到顶层、移到底层、锁定/解锁”。
- 每个菜单项使用现有 `lucide-react` 图标，图标在前、文字在后。
- 裁剪只支持 `line`、`polyline`、`curve`、`freehand` 路径对象。
- 文字、标签、连接器、表格、辅材、线束占位对象和组合对象不支持裁剪，对应菜单项置灰。
- 不改变画布外其他区域的浏览器右键行为。

## 交互设计

### 空白画布右键

1. 阻止浏览器默认菜单。
2. 记录右键对应的画布坐标和屏幕坐标。
3. 显示“粘贴”菜单项；内部剪贴板为空时置灰。
4. 粘贴时以右键画布坐标作为复制对象集合包围盒的左上定位基准，并保持多对象之间的相对位置。
5. 粘贴完成后选中新对象，并产生一次撤销历史快照。

### 实体右键

1. 命中实体不在当前选区时，先将其设为唯一选中实体。
2. 命中实体已在多选选区中时，保留当前多选。
3. 复制、删除、移到顶层、移到底层和锁定/解锁作用于当前选区。
4. 裁剪只作用于本次右键命中的单个路径实体。
5. 锁定实体不能删除或裁剪；选区全锁定时相关菜单项置灰。
6. 锁定状态一致时显示“锁定”或“解锁”；混合状态时执行统一锁定，与现有工具栏行为一致。

### 菜单关闭

执行菜单命令、点击菜单外部、按 `Escape`、开始新的画布指针操作、窗口滚动或尺寸变化时关闭菜单。菜单位置需限制在视口内，避免超出右侧或底部边界。

## 组件与数据流

### `StandaloneDrawingCanvas`

- 在 Canvas 上处理 `contextmenu`，调用 `preventDefault()`。
- 使用现有坐标换算和 `getDrawingObjectAtPoint` 得到画布坐标与命中实体。
- 通过新回调向页面发送 `{ objectId, canvasPoint, clientPoint }`，不在 Canvas 内执行剪贴板或文档命令。

### `DrawingWorkbenchPage`

- 维护右键菜单状态和内部剪贴板。
- 根据右键目标修正选区。
- 复用现有删除、图层、锁定、历史和复制逻辑。
- 增加按右键坐标粘贴的入口。
- 调用路径裁剪命令，并用两个新路径替换原路径。

### `DrawingCanvasContextMenu`

- 新建轻量展示组件，负责菜单布局、图标、禁用状态、视口边界定位及外部关闭。
- 不直接读取或修改 Drawing Store；所有操作通过回调传入。

### `drawingCommands`

- 新增纯函数 `splitDrawingPathAtPoint(document, objectId, point)`。
- 对路径的每个相邻点组成的线段计算右键点的最近投影。
- 在最近线段插入投影点，将点序列拆成前后两段。
- 两段必须各自包含至少两个不同点；右键过于接近端点时不拆分。
- 两个新对象继承原对象类型、样式、正交属性、可见性和锁定之外的业务属性，重新计算包围盒、ID 和相邻图层顺序。
- 一次命令只更新一次文档时间并返回替换对象 ID，供页面更新选区。

## 路径裁剪规则

- `line`：按投影点生成两条直线。
- `polyline`：在最近线段插入投影点并拆分点数组。
- `freehand`：按采样点之间的最近线段拆分。
- `curve`：沿当前控制点序列的最近线段确定拆分位置；拆分后的两段仍保持 `curve` 类型。
- 文字及非路径对象返回未改变结果。
- 锁定路径返回未改变结果。
- 裁剪结果保持原路径的视觉样式；两段分别重新计算 `x/y/width/height`。

## 错误与边界处理

- 剪贴板为空时不执行粘贴。
- 右键目标已删除或文档更新后不存在时关闭菜单，不执行命令。
- 裁剪点位于端点容差内、路径点不足或所有点重合时，保持原文档并关闭菜单。
- 标题栏对象和锁定对象不允许通过菜单删除或裁剪。

## 测试与验收

- 单元测试覆盖直线、折线、自由画笔的中点裁剪，端点拒绝、锁定对象拒绝和文字拒绝。
- 单元测试覆盖按右键位置粘贴时保持多对象相对位置。
- UI 契约测试覆盖画布 `contextmenu` 回调、空白菜单和实体菜单全部文字与图标。
- 浏览器走查：确认画布不再出现浏览器菜单；空白右键可粘贴；实体右键可复制、删除、图层调整、锁定；路径裁剪后生成两段；文字裁剪置灰。
- 运行全量测试、ESLint、TypeScript 和生产构建。

## 非目标

- 不提供文字裁剪。
- 不裁剪连接器、表格、辅材、线束占位框或组合对象。
- 不使用系统剪贴板；继续使用当前页面内部剪贴板。
- 不改变现有 `Ctrl+X` 渐进拆分快捷键语义。
