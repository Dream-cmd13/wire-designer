# 整表八手柄等比缩放设计

## 目标

整张表格处于八手柄选中状态时，任意缩放手柄都控制完整表格。拖动后，表格外框、内部列宽、行高、文字尺寸、文字偏移和线宽同步缩放，不产生仅扩大外框形成的空白区域。

## 适用对象

- 普通表格。
- 物料表。
- 接线表。
- 默认版本表和右下角标题栏表格。

该规则仅适用于整表八手柄。双击进入单元格或文字局部选择后，局部八手柄继续沿用现有单元格/文字调整逻辑。

## 缩放规则

### 角手柄

拖动左上、右上、右下、左下角时：

- 保持原表格宽高比。
- 对角点固定。
- 根据鼠标在表格局部坐标中的位移计算统一缩放比例。
- 内部网格、文字和线宽使用相同缩放比例。

### 边手柄

拖动上、右、下、左边手柄时：

- 保持原表格宽高比。
- 被拖动边的对边保持固定。
- 鼠标在主轴上的位移决定统一缩放比例。
- 另一轴围绕原表格中心同步扩张或收缩。
- 例如拖动右边柄时，左边保持固定，高度围绕原中心上下等量变化。

### 最小尺寸与翻转

- 继续复用现有对象缩放的最小尺寸限制。
- 拖过固定边时允许沿用现有手柄翻转语义，活动手柄切换到对侧。
- 所有计算使用表格旋转后的局部坐标，旋转表格的固定边规则保持一致。

## 数据更新

整表缩放不能只提交外框 width/height。应基于统一比例调用或扩展现有 scaleDrawingTable，使一次更新同时包含：

- x、y、width、height。
- columnWidths。
- titleRowHeight、headerRowHeight、rowHeights。
- textOffsets。
- textSizes 的 width、height、fontSize。
- style.strokeWidth 和 style.fontSize。

现有 scaleDrawingTable 以中心缩放，需要新增能够应用指定固定锚点的整表缩放纯函数，或在其结果上按固定边/固定角重新计算 x、y。计算应集中在纯函数中，不在 React 指针事件中复制表格布局缩放逻辑。

## 交互边界

- 整表选中且没有局部 tableTarget 时，八手柄使用整表等比缩放。
- 存在单元格或文字局部 tableTarget 时，继续使用 table-resize 分支调整局部目标。
- 鼠标滚轮在整表上缩放仍以表格中心为基准，不受本次固定边规则影响。
- 缩放开始只创建一次撤销快照，拖动过程中持续更新同一操作。
- 锁定表格不可缩放。

## 测试

### 纯函数

- 右边柄放大时左边固定，宽高按同一比例变化。
- 左边柄缩小时右边固定，宽高按同一比例变化。
- 上下边柄保持宽高比，并让另一轴围绕中心变化。
- 四个角手柄保持对角点固定。
- 列宽、行高、字号、文字尺寸、文字偏移和线宽使用同一比例。
- 旋转表格按局部坐标缩放。
- 最小尺寸及手柄翻转符合现有规则。

### 画布接线

- 整表 resize 分支识别表格并调用整表缩放函数，而不是直接提交通用 resizeDrawingObject 的外框 patch。
- 局部 table-resize 分支保持不变。
- 非表格对象继续使用现有通用缩放。

## 验收

1. 点击表格边缘或框选整表，显示整表八手柄。
2. 分别拖动左、右、上、下边柄，表格整体等比缩放，对边固定，没有新增空白。
3. 拖动四个角，内部网格和文字同步缩放。
4. 双击进入单元格或文字局部八手柄，局部调整行为不变。
5. 对默认三表格、普通表格和物料表重复验证。
