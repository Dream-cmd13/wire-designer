# 绘图工具栏、PDF 文件名与路径断开设计

## 目标

简化顶部图层操作，区分局部锁定与全局锁定，在 PDF 导出前允许命名，并确保绘图过程被其他操作或右键明确断开。

## 交互设计

- 顶部图层区域只显示一个“图层”图标。点击后在按钮下方展开三个图标：上移、下移、锁定/解锁当前选择。
- 图层弹层中的三个操作在未选择对象时仍可点击，并显示 Toast“请先选择一个对象。”；弹层外点击或 Escape 关闭弹层。
- 顶部另保留一个全局锁定/解锁按钮。只要存在未锁定的可编辑对象，点击即锁定全部；全部可编辑对象已锁定时，点击即解锁全部。`title-block` 不参与。
- PDF 按钮先打开文件名对话框。默认值为图号，无图号时使用图纸名称。空白文件名不可确认；导出层继续使用既有安全文件名规则并补充 `.pdf`。
- 直线、折线、曲线和自由画笔的有效草稿在右键、工具栏操作、资源操作、图层/锁定操作或 PDF 操作开始前保存为独立对象，然后清空草稿。少于两个点的草稿直接清空。
- 路径断开后保持当前绘图工具；下一次左键从新点开始新对象。右键位置不得加入路径；绘图工具下不打开上下文菜单，选择工具下保持既有菜单。

## 自由画笔与线属性补充

- 自由画笔继续支持按住左键拖动绘制自由路径；未发生拖动的左键单击立即生成一个使用当前颜色和粗细的圆点，不等待第二次单击。
- 直线、折线、曲线或自由画笔工具处于激活状态时不显示八个缩放手柄；只有选择工具下左键选中对象后才显示变换手柄。
- 选择工具下双击任意直线、折线、曲线或自由画笔对象，打开“调整线属性”弹窗。
- 新线对象按创建顺序获得默认名称“线1”“线2”……，名称只作为对象属性保存，不绘制在画布上，并可在弹窗中修改。
- 弹窗支持名称、保持当前角度/水平/垂直对齐、颜色、粗细和长度。长度缩放与对齐旋转都以路径首点为基准，并保留折线或曲线的整体形状。
- 单点圆点可修改名称、颜色和粗细；其对齐与长度不可用。
- 确定将全部修改作为一次可撤销操作写入，取消不修改对象。

## 状态与命令

- 页面继续通过 `drawingAction` 向画布发送显式 `finish` 边界；新增统一的 `breakDrawingPath` 入口，供非绘图操作调用。
- 当前选择锁定继续调用 `toggleDrawingLocks(document, selectedObjectIds)`。
- 全局锁定传入所有非 `title-block` 对象 ID，复用同一命令与历史记录机制。
- PDF 对话框状态由页面持有，实际下载函数接收可选的文件名参数。

## 错误处理与可访问性

- Toast 使用 `role="status"` 并可自动消失，也可手动关闭。
- PDF 对话框使用 `role="dialog"`、可见标题、关联输入标签；Escape 取消，Enter 确认。
- 导出失败保留现有错误提示和重试能力；重试沿用已确认的文件名。

## 验证

- 命令测试覆盖全局锁定/解锁且排除图框。
- UI 合约测试覆盖单一图层入口、三项弹层操作、未选择 Toast、PDF 文件名对话框与路径断开入口。
- 画布交互测试覆盖右键触发 finish、右键位置不加入路径，以及断开后保持工具。
- 运行完整 Vitest、ESLint 与生产构建。
