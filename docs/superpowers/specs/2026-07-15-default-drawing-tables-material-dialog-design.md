# 制作图纸默认三表格与物料表交互设计

## 目标

仅修改“制作图纸”模块的新建画布初始化和相关物料表交互。新建图纸默认显示左下角物料表、右上角变更记录表、右下角标题栏表，并允许用户通过物料表弹窗维护当前图纸物料、查询或新增公司物料、导出 XLSX。

已保存的旧图纸不迁移、不替换，也不覆盖用户已有布局。

## 默认图纸布局

新建图纸保留内部隐藏的文档元数据对象，但可见表格固定为以下三个，不再默认创建接线表。

### 左下角：物料表

- 位置保持在画布左下角区域，并与页面边缘保留现有安全间距。
- 初始只有一行表头，没有物料数据行。
- 固定列顺序为：`序号`、`物料编码`、`物料名称/规格`、`单位`、`用量`、`备注`。
- 不显示独立表名行，避免初始状态多出一行。
- 双击表头或表格区域打开画布中央的“物料表”弹窗；该动作优先于普通表格的局部文字编辑。
- 表格仍支持现有的整体选中、八个控制手柄、整体拖动、滚轮等比例缩放和局部单元格操作。

### 右上角：变更记录表

- 三行四列，不显示独立表名行。
- 第一行为表头：`版本`、`变更内容`、`日期`、`变更者`。
- 第二行为：`A`、`新版发行`、新建图纸当天日期、空白。
- 第三行四列均为空白。
- 日期在创建新图纸时按本地日期生成，格式为 `YYYY.MM.DD`，不包含任何括号或说明文字。

### 右下角：标题栏表

- 使用五行九列的基础网格和合并单元格描述，不显示普通表格的独立表名行或列标题行。
- 第 1 行：C1-C5 合并显示 `xxx公司`；C6-C9 合并为“品名”区域，显示 `品名`。
- 第 2 行：依次显示 `版本`、`A`、`绘制`、空白、创建当天日期、`料号`，C7-C9 合并为空白。
- 第 3 行：依次显示 `图幅`、`A4`、`审查`、空白、空白、`客户料号`，C7-C9 合并为空白。
- 第 4 行：C1-C2 与第 5 行对应区域纵向合并，用于绘制标准化的投影图标；其余单元格依次显示 `核准`、空白、空白、`单位`、`mm`、`比例`、`none`。
- 第 5 行：显示 `工程图号`，C4-C5 合并为空白，显示 `页次`，C7-C9 合并显示 `1 of 1`。
- 工程图号区域与文档的图纸编号保持一致。

## 表格模型与渲染

在现有 drawing table 类型上添加可选用途标识和可选合并单元格配置。普通表格及旧图纸没有这些字段时继续按现有布局解析，保证向后兼容。

合并单元格使用基于行列索引的矩形区域描述。布局解析器负责过滤被合并区域覆盖的从属单元格，并为主单元格计算累计宽高。画布 DOM 表格层、Canvas 渲染器以及 PDF、SVG、PNG 导出共用同一份解析结果，确保边框、文字和合并关系一致。

物料表通过用途标识识别双击行为；其他普通表格继续使用现有的第一次双击选择局部目标、再次双击同一文字进入编辑的行为。

## 物料表弹窗

弹窗位于画布中央，包含“当前物料表”和“公司物料表”两个 Tab。

### 当前物料表

- 显示当前图纸左下角物料表中的全部数据行。
- 提供“添加物料”和“导出物料表（XLSX）”两个按钮。
- “添加物料”打开子弹窗，字段为：
  - 物料编码，提示 `请输入物料编码`；
  - 物料名称/规格，提示 `输入或选择物料规格`；
  - 单位，提示 `请输入或选择单位`；
  - 用量，提示 `请输入用量`；
  - 备注，提示 `请输入备注`。
- 物料名称/规格和单位既可自由输入，也可从当前已加载的公司物料候选值中选择。
- 保存后追加到当前图纸物料表，序号按 `1`、`2`、`3` 顺序重新生成，并形成一个可撤销的图纸修改记录。

### 公司物料表

- 顶部包含物料名称/规格搜索框，以及“搜索”“新增物料”“重置”按钮。
- 列顺序为：`序号`、`物料编码`、`物料名称/规格`、`单位`、`操作`、`备注`。
- 搜索匹配物料名称、编码、规格和备注。
- 每行“操作”列提供“添加”按钮，点击后打开当前图纸添加物料子弹窗，预填编码、名称/规格和单位，用户填写用量和备注后加入当前图纸。
- “新增物料”复用物料表单，但保存目标为公司物料库；公司物料不记录用量，用量字段在该模式下不参与公司物料保存。

## 公司物料数据映射

公司物料使用现有 Supabase `catalog_items` 与 `accessory_specs`：

- 物料编码映射到 `catalog_items.model`，并生成符合约束的唯一 `legacy_key`。
- 物料名称映射到 `catalog_items.resource_name`。
- 备注映射到 `catalog_items.short_description`。
- 规格和单位映射到 `accessory_specs.specification` 与 `accessory_specs.unit`。
- 类型使用 `accessory`，分类使用制作图纸已有的“绘图辅材”分类。

新增时先以 `draft` 创建 `catalog_items`，随后创建 `accessory_specs`，最后将物料状态更新为 `active`，以满足数据库对活动物料必须存在规格记录的完整性约束。任一步失败都显示中文错误；未完成激活的草稿不显示在公司物料结果中，也不会自动加入当前图纸。

## XLSX 导出

- 只导出当前图纸的物料数据，不导出公司物料库。
- 固定列顺序为：序号、物料编码、物料名称/规格、单位、用量、备注。
- 默认文件名为 `<图纸编号>-物料表.xlsx`；图纸编号为空时回退到图纸名称。
- 使用标准 XLSX 生成库输出真正的 `.xlsx` 文件，确保 Excel 和 WPS 可直接打开。
- 没有物料数据时仍导出包含表头的空工作表。

## 错误处理

- 公司物料加载、搜索、新增和 XLSX 导出失败时，统一通过现有中文错误转换显示中文提示。
- 加载失败保留弹窗和当前图纸数据，并提供重试入口。
- 表单必填项在提交前校验，错误定位到对应字段，不提交不完整数据。
- 当前图纸物料新增与 Supabase 公司物料新增相互独立，远程失败不修改当前图纸。

## 测试与验收

自动测试覆盖：

- 新建图纸只有三个可见默认表格，并具有指定位置、列、行、合并配置和本地动态日期。
- 旧表格无新字段时仍能使用现有布局。
- 合并单元格的边界计算、DOM 渲染和导出渲染一致。
- BOM 行追加及序号自动生成，且不修改其他表格。
- 公司物料的读取、搜索、字段映射、草稿到激活写入顺序和中文错误。
- XLSX 工作表名称、表头、数据和默认文件名。
- 双击默认物料表打开物料弹窗，普通表格保留原双击编辑行为。

浏览器验收覆盖：

- 新建制作图纸后三个表格的位置和内容正确。
- 三个表格原有整体拖动、八手柄和滚轮缩放可用。
- 物料表弹窗两个 Tab、当前物料添加、公司物料搜索/重置/新增/添加可用。
- XLSX 文件可下载并由 Excel/WPS 正常打开。
- 画布显示与 PDF、PNG、SVG 导出的标题栏合并布局一致。

## 非目标

- 不迁移或替换已经保存在浏览器中的旧图纸。
- 不修改制作图纸以外的 BOM、报价或物料选择模块。
- 不增加公司物料的删除、批量编辑、分页或分类管理。
- 不改变非物料表的既有双击局部编辑规则。
