# 中文错误提示、滚轮缩放与表格交互设计

## 目标

在不更换现有 Canvas、DOM 表格和 SVG 变换覆盖层架构的前提下，完成三项交互增强：

1. 所有面向用户的错误提示显示为中文，不直接暴露后端英文错误。
2. 根据鼠标位置，用滚轮缩放当前选中对象或画布。
3. 创建表格前填写行列参数，并明确区分表格整体、单元格和文字的选择与调整。

本次坚持最小修改原则，不重构无关页面，不改用新的画布框架，也不将 DOM 表格重写为 Canvas 表格。

## 现状

- 多个页面直接展示 `error.message`，Supabase schema cache、网络和权限错误会以英文出现在界面中。
- 图纸工作台的缩放值固定为 `0.72`，独立画布尚未处理滚轮缩放。
- 点击工具栏“表格”会直接创建默认表格，没有行数、列数和表名行选项。
- DOM 表格已经支持表格整体拖动和文字偏移，但当前选择模型只识别图纸对象，不能独立表示单元格和表格文字。
- 现有 SVG 变换覆盖层已经提供八个缩放手柄，可在保持架构的情况下扩展目标类型。

## 总体架构

### 中文错误转换

新增一个纯函数错误转换模块。调用方传入未知异常和可选业务上下文，模块根据错误代码、HTTP 状态及英文消息特征返回适合用户阅读的中文提示。

页面捕获异常后执行三件事：

1. 将原始错误对象输出到开发控制台，保留排查信息。
2. 使用转换函数生成中文消息。
3. 只把中文消息交给 Toast、错误区域或重试组件。

扫描现有所有直接展示异常消息的入口并接入转换函数，不把修改限定在图纸页面。

### 滚轮缩放

`DrawingWorkbenchPage` 持有画布缩放比例和撤销历史。`StandaloneDrawingCanvas` 根据滚轮事件的画布坐标、当前选择目标和目标边界判断缩放对象还是画布，并通过回调提交变化。

命中规则如下：

- 鼠标位于当前已选中且可编辑目标的边界内时，缩放该目标。
- 鼠标位于未选中对象、锁定对象、不可编辑对象或画布空白处时，缩放画布。
- 不因鼠标恰好位于未选中对象上而自动选择或缩放该对象。

### 表格交互目标

保留图纸对象选择状态，同时为活动表格增加局部交互目标：

- `table`：整个表格。
- `table-cell`：指定行列的单元格。
- `table-text`：表名、列标题或数据单元格中的文字。

任一时刻只显示当前目标的一组八个手柄。局部目标依附于所属表格；取消表格选择、删除表格或切换文档时同时清除局部目标。

## 错误中文化规则

转换函数按从具体到通用的顺序匹配：

1. 已知 Supabase 表缺失或 schema cache 未刷新。
2. 数据库字段缺失。
3. 登录失效或无访问权限。
4. 网络失败或请求超时。
5. 唯一约束、版本或数据冲突。
6. 调用方提供的中文业务回退消息。
7. 通用消息“操作失败，请稍后重试。”

已知表提供业务化提示：

- `public.catalog_items`：`公共资源数据表不存在或尚未初始化，请联系管理员完成数据库配置。`
- `public.drawing_icons`：`绘图图标数据表不存在或尚未初始化，请联系管理员完成数据库配置。`

其他缺失表使用：`所需数据表不存在或尚未初始化，请联系管理员完成数据库配置。`

重试按钮、关闭按钮和辅助文本继续使用中文。错误消息中不拼接英文原文。

## 滚轮缩放交互

### 画布缩放

- 画布缩放范围为 25%～300%。
- 每个滚轮刻度按约 10% 的倍率缩放，并对最终值执行边界限制。
- 左上角始终是固定原点。缩放只改变内容比例，不引入居中偏移，也不自动改变滚动位置。
- 画布尺寸和 DOM 表格层、Canvas 渲染层、SVG 交互层使用同一个缩放值。

### 对象缩放

- 对象相对开始缩放时的尺寸限制在 20%～500%。
- 缩放保持宽高比例，并围绕对象视觉中心更新 `x`、`y`、`width` 和 `height`。
- 表格整体缩放时同步缩放列宽、行高、字体大小和文字偏移，使内部布局与表格保持一致。
- 单元格目标缩放时同步调整该单元格所在整列的宽度和整行的高度，不允许单元格脱离网格。
- 文字目标缩放时调整文字区域与字号，保持文字中心稳定，不改变单元格边界。
- 锁定对象和不可编辑对象不响应对象缩放，此时事件按画布缩放处理。
- 缩放后继续显示当前目标的八个控制手柄。

### 撤销语义

一段连续滚轮输入合并成一个撤销操作：第一次滚轮事件记录开始快照，后续相邻滚轮事件继续更新同一操作；停止滚轮输入一小段时间后结束该操作。画布视图缩放不修改图纸文档，不进入文档撤销历史；对象、单元格和文字缩放进入撤销历史。

## 表格创建

点击工具栏“表格”后先打开创建弹窗。弹窗包含：

- 数据行数。
- 列数。
- 是否显示表名行。

数据行数不包含固定存在的列标题行，也不包含可选表名行。例如 3 行、4 列并启用表名行时，最终呈现为 1 行表名、1 行列标题和 3 行数据。

校验规则：

- 行数和列数必须是正整数。
- 使用合理的产品上限防止一次创建过大的 DOM 表格；达到上限时在弹窗内显示中文校验消息。
- 确认按钮只在输入有效时创建表格。

新表格使用“列1、列2……”作为默认列标题，表名行默认文字为“表格”。创建后自动选中整个表格并显示八个手柄。

旧图纸中的表格缺少新增布局字段时，渲染层根据现有 `width`、`height`、列数和行数生成默认列宽与行高，不要求迁移已有数据。

## 表格选择、拖动与手柄

### 命中与选择

- 点击表名、列标题或数据文字：选择对应 `table-text`。
- 点击单元格文字以外的空白区域：选择对应 `table-cell`。
- 点击表名行空白、表格外边框或明确的表格拖动区域：选择 `table`。
- 当前目标显示八个手柄，其他层级不显示。
- 双击文字继续进入现有可编辑状态；编辑期间隐藏变换手柄，避免拖动与文字输入竞争指针事件。

### 拖动与调整

- 拖动文字只改变文字在所属区域内的偏移，不改变单元格。
- 单元格不能脱离网格。拖动单元格本体保持其行列归属，不执行自由位置移动。
- 单元格左右手柄调整所在整列宽度。
- 单元格上下手柄调整所在整行高度。
- 单元格四角手柄同时调整所在整列宽度和整行高度。
- 拖动表格边框或表格拖动区域移动整个表格。
- 表格整体的八个手柄继续调整表格整体尺寸，内部列宽和行高按比例变化。

每次指针手势只创建一条撤销记录。调整时设置合理的最小列宽、最小行高和最小文字尺寸，避免目标缩小到不可操作。

## 数据兼容

表格布局扩展字段均为可选字段，包括：

- 是否显示表名行。
- 各列宽度。
- 表名行、列标题行和各数据行的高度。
- 文字区域尺寸及局部偏移。

读取旧数据时即时推导默认值；只有用户实际调整后才写入明确布局值。导出 PNG、SVG 和 PDF 时使用与工作台相同的解析后布局，确保屏幕与导出一致。

## 测试与验收

### 自动测试

- 错误映射：已知缺失表、未知缺失表、字段缺失、权限、网络、冲突和未知异常。
- 错误入口：不再直接向用户展示英文 `error.message`。
- 滚轮命中：选中目标内缩放对象，目标外或锁定目标内缩放画布，未选中对象不被缩放。
- 画布缩放：左上角固定，范围为 25%～300%。
- 对象缩放：中心点不变、宽高等比、范围为 20%～500%。
- 撤销：连续对象滚轮缩放合并为一次撤销；画布缩放不进入文档历史。
- 表格创建：行列参数、可选表名行、默认标题和无效输入。
- 表格兼容：旧表格缺少布局字段时正常渲染。
- 表格目标：整体、单元格和文字分别显示唯一一组八手柄。
- 单元格调整：整列宽度、整行高度及组合调整保持网格结构。

### 浏览器走查

- 触发 `catalog_items`、`drawing_icons` 和通用请求错误，确认界面只显示中文且重试有效。
- 在不同画布缩放比例下验证鼠标命中、左上角固定和 DOM/Canvas/SVG 三层对齐。
- 分别滚轮缩放普通对象、表格整体、单元格和文字，并执行撤销/重做。
- 创建不同规模且包含或不包含表名行的表格。
- 依次选择、拖动和调整表格整体、单元格与文字，确认手柄目标明确。
- 导出包含自定义表格布局的 PDF、PNG 和 SVG，确认布局一致。

最终运行完整测试、Lint、生产构建和 `git diff --check`。

## 不在本次范围内

- 不新增任意单元格脱离网格或跨行跨列功能。
- 不重写图纸撤销系统。
- 不把 DOM 表格迁移到 Canvas。
- 不修改 Supabase 数据库结构来解决缺表问题；本次只中文化客户端错误。
- 不改变上一项绘图模式十字准星功能。
