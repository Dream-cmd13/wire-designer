# 制作图纸向导与绘图工作台补全设计

日期：2026-07-14
状态：已确认

## 1. 目标

在保留现有 React、TypeScript、Canvas、Zustand、Supabase 与导出实现的前提下，补齐“制作图纸”中的配置向导、公共绘图资源、交互式绘线、对象编辑、图层、锁定、拆分和快捷键，形成可以从公共资源选型、生成制造图、继续编辑并导出 PDF 的完整流程。

本次坚持最小修改原则：复用现有 `DrawingDocument`、独立图纸 Store、Canvas 渲染器、表格 DOM 编辑层、PDF/PNG/SVG 导出和 Supabase catalog，不迁移到新的画布框架，也不重构无关页面。

## 2. 已确认范围

- 资源仅支持公共资源，统一从 Supabase 读取。
- 不实现私人资源、用户资源隔离或私人资源权限策略。
- 向导支持内线、外线和图库入口。
- 子类型仅支持单头、双头；隐藏 `1:1:N`。
- 线材类型支持普通线、绞线、排线、并线和屏蔽线。
- 支持连接器、模型、线材、辅材、包装方式、图库模板、常用语和绘图图标等公共数据。
- 支持真正的直线、折线、曲线和自由画笔交互。
- 支持清空画板、单选、框选、多选、删除、锁定、图层调整和两级拆分。
- 支持本地草稿持久化，以及 PDF、PNG、SVG 下载。

## 3. 非目标

- 不实现 `1:1:N` 拓扑及其接线规则。
- 不实现协同编辑、账号级图纸共享或云端图纸草稿保存。
- 不迁移到 Fabric.js、Konva 等第三方画布框架。
- 不实现传统剪切；`Ctrl+X` 专用于拆分元素。
- 不重构项目中的 Harness 主编辑器或 `TwoDView`。

## 4. 总体架构

### 4.1 前端边界

保留 `DrawingWorkbenchPage` 作为工作台编排层，并将新增职责放入聚焦组件或纯函数：

- 向导组件负责四步表单、公共资源选择、校验和生成确认。
- 资源面板负责按类别读取 Supabase、筛选并创建画布对象。
- 工具栏负责切换工具模式和触发文档级命令。
- Canvas 负责命中测试、框选、拖动和绘制指针事件。
- 对象属性面板负责位置、样式、层级、锁定和业务属性。
- 文档命令纯函数负责清空、图层变更、锁定和拆分，便于测试和进入撤销历史。

### 4.2 数据流

1. 页面通过公共资源仓库读取 Supabase catalog、图库模板、常用语和图标。
2. 向导把筛选后的资源引用、线材配置和接线行写入 `DrawingWizardDraft`。
3. 生成器校验草稿并生成 `DrawingDocument`，包含连接器、组合线束、尺寸、接线表、BOM、技术要求和标题栏。
4. 工作台所有修改生成新的文档状态并写入现有 Zustand Store，同时记录撤销快照。
5. 渲染器绘制同一份文档；PDF、PNG、SVG 导出继续复用该文档，避免预览与导出结构分叉。

## 5. 配置向导设计

### 5.1 第一步：类型配置

- 类型：内线、外线、图库。
- 子类型：单头、双头。
- 线材类型：普通线、绞线、排线、并线、屏蔽线。
- 外线默认启用模具，但用户可以在属性步骤修改。
- 图库类型进入公共模板选择流程；模板载入后仍然生成普通可编辑 `DrawingDocument`。

### 5.2 第二步：连接器或模型选择

支持以下独立筛选条件：

- 资源类型：连接器、模型。
- 名称或型号关键词。
- 公头、母头或全部。
- 类别。
- 系列。
- PIN 位数。
- 单排、双排等排位。
- 间距。

双头分别选择左端和右端资源。结果行展示缩略图、名称、型号、方向与完整规格；选中项在结果区和下一步按钮附近显示摘要。未选择所需端点时不能进入下一步。

### 5.3 第三步：属性与颜色

- 模具：有或无；外线默认有。
- 线材规格：从 Supabase 线材目录选择，例如 UL1007。
- 总长度和公差。
- 每芯颜色、长度、线号、接线号和目标 PIN。
- 批量设置统一颜色、统一长度、递增线号、顺序接线和反序接线。
- 物料种类数量根据连接器、线材、模具与辅材自动计算并只读展示，禁止用人工数量覆盖 BOM 推导结果。

### 5.4 第四步：生成预览

预览展示拓扑、端点资源、总长度、芯线数量、接线摘要、物料种类和将生成的图纸对象。以下情况阻止生成：

- 必需的连接器或模型未选择。
- 线材规格未选择。
- 总长度不大于零。
- 双头接线存在缺失或越界的目标 PIN。
- 芯线长度不大于零。

确认后自动生成连接器、组合线束、长度标注、接线表、物料表、技术要求和标题栏。

## 6. 公共资源与 Supabase 设计

### 6.1 目录主表

继续使用 `catalog_items` 保存可采购或可选型公共资源的通用字段，包括名称、型号、类别、生命周期和排序。扩展 `catalog_item_type`，增加：

- `model`
- `accessory`
- `packaging`

现有 `connector`、`wire`、`protective_sleeve`、`overmold` 保持不变。

### 6.2 独立规格表

不同资源的结构化属性不写入通用 JSON，新增一对一规格表：

- `model_specs`：模型类别、默认宽高、默认方向和可选模型参数。
- `accessory_specs`：辅材类别、规格、材质、颜色和单位。
- `packaging_specs`：包装类别、规格、单位和包装说明。

连接器筛选继续读取 `connector_specs` 中的系列、公母、PIN、排位和间距。线号与线材规格继续读取 `wire_specs` 及 `catalog_items` 名称、型号。

### 6.3 图库和编辑器资源

图库模板不属于物料目录，独立建表：

- `drawing_templates`：名称、类别、描述、缩略图路径、当前版本、状态和排序。
- `drawing_template_versions`：模板、版本号、schema 版本、图纸 JSON 和创建时间；模板与版本号唯一。
- `drawing_common_phrases`：常用语、类别、排序和启用状态。
- `drawing_icons`：图标名称、类别、SVG 路径数据、默认宽高、排序和启用状态。

图纸 JSON 使用 JSONB，但必须带 `schema_version`；前端载入后通过类型守卫校验，不能直接把任意 JSON 注入 Store。

### 6.4 SQL 交付形式

- 更新模块化标准建表 SQL，使全新数据库包含完整结构。
- 增加非破坏性升级 SQL，为已有数据库补充枚举、表、约束、索引和公共读取策略。
- Seed 使用稳定 UUID 和 `insert ... on conflict do update`，可以重复执行。
- Seed 覆盖连接器、模型、普通线材、UL1007、辅材、包装方式、图库模板、常用语和绘图图标。
- 所有资源都是公共数据，不添加 `owner_id` 或用户范围字段。

## 7. 绘图工作台交互

### 7.1 工具模式

工作台维护选择、直线、折线、曲线、自由画笔和框选等互斥工具模式。切换工具时结束或取消上一工具的临时状态。

- 直线：第一次单击起点，第二次单击终点并完成。
- 折线：单击依次增加顶点；双击、再次点击工具或按 `Escape` 完成。
- 曲线：交互规则与折线相同，渲染器对顶点进行平滑连接。
- 自由画笔：按下开始记录，移动采样，释放后生成对象。
- `Shift+Q` 切换正交约束；开启后直线和折线的新线段按水平或垂直方向吸附。

绘制中的临时预览不写入历史；完成后只产生一次文档变更和一次撤销快照。

### 7.2 选择与批量操作

- 单击选择最上层未隐藏对象。
- 空白处拖动形成框选区域。
- `Shift` 点击追加或移除多选对象。
- 删除、锁定、颜色、线宽和图层命令作用于当前全部选中对象。
- 锁定对象仍可被选中以便解锁，但不能移动、删除、拆分或修改属性。

### 7.3 清空画板

工具栏增加“清空画板”。该命令删除所有非基础图框对象，保留标题栏与基础图框，清除选择，并产生一个可撤销快照。空画板重复执行不产生历史记录。

快捷键 `Ctrl+U` 调用同一命令。

### 7.4 图层设置

选中对象后支持：

- 置顶。
- 上移一层。
- 下移一层。
- 置底，但不低于基础图框。
- 直接输入目标层级。

每次操作后对非基础对象的 `zIndex` 做稳定归一化，避免长期编辑产生重复或极大的层级值。锁定对象必须先解锁才能调整图层。

### 7.5 锁定和解锁

工具栏与属性面板提供同一锁定切换命令。多选对象中只要存在未锁定对象，点击后统一锁定；全部已锁定时点击则统一解锁。

### 7.6 文字、标注、序号和图标

- 文字工具支持自定义文字与 Supabase 常用语。
- 文字属性支持字号、颜色和已有的画布内编辑。
- 号码工具生成可编辑号码管或标签对象。
- 长度标注生成可编辑尺寸对象。
- 序号工具提供带圈序号。
- 图标工具从 Supabase `drawing_icons` 选择并生成可缩放 SVG 图标对象。

### 7.7 表格和颜色

- 表格工具创建前选择标题、行数和列数。
- 接线表与物料表可以从当前图纸数据重新生成，也可以插入空白模板。
- 保留表格整体拖动、单元格文字独立拖动和双击编辑。
- 填充色、边线色、文字色与线宽放在属性面板，多选时批量应用。

## 8. `Ctrl+X` 两级拆分

新增可嵌套组合对象，组合对象保存子对象和相对坐标。拆分命令只作用于可拆分且未锁定的选中对象。

1. 第一次选择完整线束并按 `Ctrl+X`：组合线束替换为多个芯线组。每个芯线组可以独立调整颜色、粗细、位置和图层。
2. 第二次选择芯线组并按 `Ctrl+X`：芯线组替换为线条、线号文字和端点标注等基础对象。
3. 基础对象不再拆分；命令不修改文档，只显示轻量提示。

替换出的子对象继承父对象的页面坐标、可见性和有效层级；拆分产生一次撤销快照，`Ctrl+Z` 可以完整恢复拆分前的组合层级。

## 9. 快捷键

- `Ctrl+C`：复制当前选择。
- `Ctrl+V`：粘贴并偏移复制对象。
- `Ctrl+U`：清空画板。
- `Ctrl+X`：逐级拆分。
- `Delete`：删除未锁定选择对象。
- `Shift+Q`：切换正交模式。
- `Shift+W`：直线工具。
- `Shift+E`：折线工具。
- `Shift+R`：曲线工具。
- `Escape`：结束当前连续绘制，或取消尚未形成有效对象的绘制。

输入框、文本域和画布内文字编辑聚焦时不触发全局快捷键。

## 10. 错误与空状态

- Supabase 加载时显示加载状态。
- 查询失败显示错误原因摘要和重试按钮，不静默回退到本地模拟资源。
- 查询成功但没有结果时显示空状态和清除筛选入口。
- 已选资源在下一步前被删除或停用时，清除失效选择并阻止生成。
- 图库 JSON schema 不兼容时不载入模板，并显示模板版本不受支持。
- PDF、PNG 或 SVG 导出失败时保留当前图纸，显示错误提示，不能错误标记为已导出。

## 11. 测试与验收

### 11.1 自动化测试

- 资源仓库：Supabase 行映射、全部筛选条件、失败和空结果。
- 向导：单头、双头、外线默认模具、图库模板、必填校验、批量线号和正反序接线。
- 生成器：连接器、组合线束、尺寸、接线表、BOM、技术要求和标题栏。
- 文档命令：清空、锁定、批量解锁、图层置顶/上移/下移/置底/指定层级、层级归一化。
- 拆分：线束到芯线组、芯线组到基础对象、锁定对象不拆分、基础对象不变化、撤销恢复。
- Canvas：框选、多选、绘制完成、正交吸附和自由画笔采样。
- 快捷键：所有映射以及文本编辑聚焦时不触发。
- 导出：新增组合、图标和线条对象在 SVG、PNG、PDF 中与预览一致。

### 11.2 SQL 验证

- 标准建表脚本可以从空库执行。
- 升级脚本可以在已有结构上执行且不删除业务数据。
- Seed 连续执行两次不产生重复数据。
- 外键、唯一约束、索引和公共读取策略有效。

### 11.3 页面走查

1. 通过向导生成一张双头屏蔽线图纸。
2. 使用全部连接器筛选条件分别选择左右资源。
3. 批量设置线号和反序接线并验证接线表与 BOM。
4. 绘制直线、正交折线、曲线和自由线。
5. 框选多个对象，调整颜色和图层，再锁定与解锁。
6. 清空画板并撤销恢复。
7. 对线束执行两次 `Ctrl+X`，独立修改芯线颜色并撤销。
8. 导出 PDF，并验证内容与画布一致。
