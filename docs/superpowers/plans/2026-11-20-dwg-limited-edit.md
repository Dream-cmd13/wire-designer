# DWG 原图限定编辑实施计划（方案 B）

**目标**　工程师从现有 DWG 页面打开本地图或本人云端图，点选并修改原图上的文字、技术要求或尺寸显示文字，下载可由 CAD 继续编辑的 DWG，也可以把结果另存到云端。

**架构**　浏览器保留源文件和待应用的编辑操作，沿用 Canvas 预览。自有 .NET 服务用 ACadSharp 修改原 DWG 对象并返回新文件。前端用项目现有解析器重开返回的字节，下载与云端保存使用同一份结果。

**技术栈**　React、TypeScript、`@mlightcad/libredwg-web`、ASP.NET Core、ACadSharp、Supabase 私有 Storage。ACadSharp `3.8.35` 是已有实验的复现起点。实施者可按下列任务逐项执行和验证。

## 一、工程师实际怎么用

| 步骤 | 本地拖入或选择文件 | 从本人云图库打开 |
| --- | --- | --- |
| 打开、进入「编辑图纸」 | 浏览器本地解析，保留原 `File`。进入编辑和修改草稿均在本机完成 | 复用经 SHA-256 校验的私有原件，绑定当前 `asset.id` 和源文件 SHA-256 |
| 选中、修改、预览 | 点选文字，属性面板显示对象类型、原值和草稿。支持多行输入、应用到预览、撤回本次改动 | 相同的操作。点击尺寸线或尺寸文字，选中的都是对应尺寸对象 |
| 生成并下载 | 首次发送本图前说明「生成 DWG 需要将图纸发送到本系统的转换服务，文件仅用于本次处理」，用户可取消。成功后下载如 `原文件名_修订.dwg` | 可直接生成并下载。生成中显示进度状态，重复点击共用这一次请求 |
| 保存到云端 | 用户明确点击「保存到云端」才上传修订件。它作为独立图纸保存，无需把本地原稿也存入图库 | 点击「另存为新版」生成新的资产 ID 和对象路径，记录直接来源。列表可辨认版本，并能重新打开原版和新版 |

首版接受模型空间顶层 `TEXT`、可安全保留格式的 `MTEXT`，以及能唯一确定其显示文字的 `DIMENSION`。料号、规格、技术要求按实际实体类型处理。尺寸面板使用文案「修改尺寸显示文字」，保留测量点和几何长度。共享块定义、块实例属性、自动测量字段、复杂嵌套格式及无法唯一定位的对象继续只读，选中时说明原因。几何拉伸、移动连接器和修改块定义属于后续独立需求。

## 二、从哪里接入

| 现有位置 | 本次改动或复用点 |
| --- | --- |
| `src/pages/DwgViewerPage.tsx`、`src/lib/dwg/dwgCache.ts` | `loadFile` 与 `openCloud` 都调用 `loadBuffer`。编辑会话需持有当前原始字节或可校验的原件引用。缓存命中、换图、退出登录也要测 |
| `src/lib/dwg/parseDwg.ts`、`dwgTypes.ts`、`renderDwg.ts`（均在同目录） | 解析时建立可编辑对象索引，给对应渲染图元附来源引用。`expandDimensionBlock` 展开匿名标注块，命中其子图元时返回父尺寸 handle |
| `src/repositories/dwgRepository.ts` | 复用 `createDwgSaveSession`、`save`、`download` 的大小及哈希校验、私有路径和失败恢复。现有原件上限为 20 MiB |
| `supabase/updates/20261118_dwg_preview.sql` | 现有 `dwg_assets` 仅允许 `uploading → ready`，Storage 上传使用新路径。用增量迁移表达版本关系 |
| `server/dwg-edit/`、`tests/e2e/dwg-edit.spec.ts`（拟新增） | 自有写入服务及服务测试、浏览器下载和云端流程测试。先检查当时的代码，已有等价入口时直接复用 |

## 三、先验证 DWG 能交付

前次在内存中用真实样图取得以下基线。实施时复现并保留可重复运行的检查，原 DWG 作为只读测试输入。

| 验证对象 | 已观察到的结果 | 实施时应验证的行为 |
| --- | --- | --- |
| `M12A05-07-068-3-10-500.dwg` 中的尺寸 `9F0` | 将 `*500±10` 改成 `*750±10` 后，原始几何测量值仍约为 `105.64115` | 两个解析器均能读回新文字，同一对象的测量值和定义点与源文件一致 |
| 尺寸显示块 `*D5` 与技术要求 `B72` | 只写父尺寸时，块内仍显示 `*500±10`。同步两处后均显示新值，`B72` 的“插拔次数：500次”仍在 | 用真实输出断言父尺寸、显示块和另一条含 `500` 的技术要求。上述 handle 和块名仅用于该样图测试 |
| 仓库根目录的 9 张 `AC1018` 图 | 无改动读写后，逐图的模型空间实体数和块数一致。LibreDWG 读取原图报告 `4`（`UNHANDLEDCLASS`），读取重写件均报告 `64`（`VALUEOUTOFBOUNDS`） | 对照原件、空改写件、单对象改写件定位新增告警，比较外参、布局、线型、文字样式和打印内容。记录告警影响与目标 CAD 读回结果 |

首批兼容性依据是 `AC1018` 和这组线束样图。按实测维护可写范围，其他版本可沿用既有预览。正式对外提供 DWG 前，用工程师日常使用的 AutoCAD 或中望 CAD 打开**浏览器下载的文件**，检查打开时是否提示修复，验证模型、布局、打印和再次保存。记录软件版本和结果。缺少桌面 CAD 时先完成服务、UI 及自动化验收，将「目标 CAD 验收待完成」列为发布前事项。

## 四、实施顺序

### 1. 建立可复现的读写测试

- [ ] 在 `server/dwg-edit/` 建立最小 .NET 写入程序及测试项目 `tests/DwgEdit.Tests.csproj`（相对于该目录）。固定已验证的依赖版本。对 9 张原图做空改写，记录输入和输出 SHA-256、格式、实体及块数、解析告警。测试产物写入独立临时目录。
- [ ] 对五芯样图做三组独立编辑：普通文字（若图内缺少顶层 `TEXT`，用最小专用夹具）、含中文和段落的技术要求、尺寸 `9F0`。用 ACadSharp 和项目的 LibreDWG 读取结果，并用当前页面渲染检查显示值。把「只写父尺寸时两处值不同」作为回归用例。
- [ ] 诊断代码 `64`。如须更换 ACadSharp 版本或调整写出选项，对相同样图重跑并记录差异。按样图实测决定可写范围；会破坏文字、布局、外参或打印的输入只开放预览。

### 2. 选中原对象并形成草稿

- [ ] 在 `normalizeDwgDatabase` 收集顶层对象 handle、类型、原字段和可编辑文字范围。为渲染图元增加可选来源引用。尺寸的文字、箭头、尺寸线指向父尺寸，显示块中的文字只作为其内部引用。用隐藏图层、缩放平移、重叠文字和重复块实例测命中行为。重叠的不同目标提供选择。
- [ ] 编辑操作包含 `handle`、`kind`、`expectedText`、`newText`，其中 `kind` 取 `TEXT | MTEXT | DIMENSION`。前后端统一 `expectedText` 为编辑框中原始可见文字，换行统一为 LF，保留有意义的空格。格式模板从源 CAD 对象读取。按 handle 合并反复修改，恢复原值后移除操作。整组操作绑定 `sourceSha256`。
- [ ] 在现有页面加入编辑模式和属性面板。草稿预览只作用于当前文件。明确处理草稿撤回、放弃、换图、登出与过期请求。服务暂不可用时可继续查看原图和当前草稿。测试进入编辑和修改草稿时的网络请求，本地原件只在确认生成时发出。

### 3. 生成新的 DWG 文件

- [ ] 提供同源 `POST /api/dwg/edit`。前端发送 `multipart/form-data`，字段为 `source`（原 DWG）、`sourceSha256` 和 `operations`（JSON 数组），使用当前登录凭证。服务独立核验身份和工程师或管理员角色，复用项目可信角色来源。输入、输出均满足现有 20 MiB 文件限制。按实际部署方式提供本地启动及反向代理配置说明。
- [ ] 服务从原始 DWG 核对文件头、哈希、实体类型、作用域、旧文字和操作集合。任一项冲突则整批拒绝并返回可读原因。为 `MTEXT` 保留受支持的字体、字号、段落，正确处理中文、换行、反斜杠、花括号及 `±` 等公差符号。遇到无法安全解释的格式，将该对象标记为只读。
- [ ] `DIMENSION` 只改显示覆盖值。按该实体实际引用更新或重建其匿名块内唯一目标文字，验证显示块归属和引用是否共享。重开输出时同时核对父尺寸、显示文字及测量几何。以 DWG 二进制响应，前端拿同一个 Blob 重开预览、下载或另存。
- [ ] 把写入服务作为短时文件处理服务，使用受控内存或请求级临时文件并在结束时清理。日志记录耗时、大小、错误类型等诊断信息。返回哈希冲突、输入不受支持、超限、取消、超时的可理解反馈，保留草稿以便重试。

### 4. 云端另存与故障恢复

- [ ] 为 `dwg_assets` 提供增量迁移，新增可空 `parent_asset_id` 表示直接来源。已有行按根版本读取。数据库写入时校验父记录属于同一用户且状态为 `ready`，保留元数据不可变、私有 RLS 和新对象路径约束。本地原图首次保存修订件时父 ID 为空。
- [ ] 用修订后 DWG 的实际字节计算大小和 SHA-256，扩展 `createDwgSaveSession` 和会话匹配校验以携带父 ID。相同一次保存的双击、上传后确认失败及重试复用同一 session 和字节。原稿与新版各有独立可校验的文件。重新打开新版再修订时，父 ID 指向这次打开的版本。
- [ ] 在隔离数据库和 Storage 测试环境验证升级前后既有行数、关键字段、对象哈希和可访问性。验证跨用户父 ID、未就绪父项会被拒绝，两个合法子版本可共存。准备数据库与 Storage 的备份、恢复步骤并试演；远程 SQL 和部署另行授权。

### 5. 浏览器与交付验收

- [ ] 本地拖入真实样图，验证打开和编辑时无图纸上传请求。确认生成后从浏览器下载 DWG，检查 `AC1018` 文件头、两个尺寸文字来源、原几何和技术要求。对照原文件 SHA-256。验证取消生成、服务失败后重试、换图时旧响应失效。
- [ ] 本地模拟私有云端读写，打开原图、另存新版、刷新、分别重开对比，下载新版并比对实际文件与云端对象的 SHA-256。至少让一次浏览器用例调用真实本地写入服务。分别记录模拟云端与真实环境验证范围。
- [ ] 回归普通预览、平移缩放、图层开关、原有 PDF/PNG 导出及 M12 预览。用相同输入检查编辑模式关闭后的行为。
- [ ] 按下列命令完成适用门禁，交付实际结果、样图与仍需人工确认的项目。完成目标 CAD 验收后再标记该版本具备对外交付条件。
