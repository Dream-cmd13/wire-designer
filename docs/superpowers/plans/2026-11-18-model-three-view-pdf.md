# 云端 3D 模型导出三视图 PDF：实施说明

**交付目标：** 工程师或管理员在 `/model-viewer` 打开已有模型，确认哪一面是前视，下载一页 A4 横向 PDF。前视、顶视、右视用于核对外形、孔位朝向和防呆键方向。**这是外形参考图，不是可量测或直接投产的工程图。**

**本期方案：** 用浏览器已解析的 `ParsedModel`，通过独立的正交相机渲染三视图，合成图片后复用现有 PDF 封装。支持 STEP/STP 与 STL；不增加服务、依赖或数据库迁移。第一角法和正面选择规则是本方案的实施默认值，不代表已核实客户制图标准。配套[实施提示词](2026-11-18-model-three-view-pdf-prompt.md)可用于新的 AI 会话。

## 1. 现有能力与边界

| 仓库依据（相对项目根目录） | 对实施的约束 |
| --- | --- |
| `src/repositories/modelRepository.ts`、`src/pages/ModelViewerPage.tsx`：私有存储保留原文件；`openCloud` 核对所属用户，下载后按 `asset.source_unit` 解析。 | 已保存且能正常打开的云端模型无需重传。导出只消费当前解析结果；本地已预览文件也可直接导出。打开模型后的导出动作不额外访问存储或数据库。 |
| `src/lib/models/modelTypes.ts`、`src/lib/models/modelParser.worker.ts`：返回网格坐标、索引及毫米包围盒；STEP 已三角化，STL 已按指定单位换算。 | 保留所有网格的相对位置；不再次缩放 STL，不强制切换 STEP 质量，不把网格边界当成精确 CAD 曲线。 |
| `src/components/models/ModelViewer.tsx`、`src/lib/models/modelView.ts`：已有前、顶、右方向；交互相机是透视相机。 | 复用默认方向，不通过操作界面切换视角或截图。原有视角、缩放、选区、背景和交互手感不变。 |
| `src/lib/drawingExport.ts`：`buildImagePdf` 生成单页 `842 × 595 pt`，把 JPEG 固定绘制到 `802 × 535 pt` 的区域。 | 建议按 `2406 × 1605 px`（内容区宽高各乘 3）制作白色合成图，复用 `buildImagePdf`、`downloadBlob`。不要把整张 A4 比例的位图拉伸到此区域，不修改共享 PDF 工具的默认行为。 |

**为什么不选另外两条路：** 截取查看器三个方向会把透视、选区和各次缩放带入文件；精确矢量线稿需要从 STEP 原始几何提取投影轮廓和隐藏线。把预览图装进 PDF 不会变成工程图。本期不做 DXF/DWG、隐藏线虚线、自动尺寸、公差、PDF 云端归档、批量转换或任意角度校正。

## 2. 用户流程与纸面布局

1. 在模型页增加 **导出三视图 PDF**。仅在当前预览就绪且不在加载、解析或切换质量时可用。未完成保存的云端记录仍走原恢复流程；可预览的本地文件不要求先上传。
2. 打开确认框：默认前视面为“从 −Y 看”，可选模型坐标的 `±X / ±Y / ±Z` 六面。显示所选前视的小预览，让用户能认出插接面。选择仅对本次导出有效，不沿用自由旋转视角。取消不下载，重复确认只下载一次。
3. 文件名规则为 `<原文件名去扩展名>_三视图.pdf`；清理非法字符，空名回退为 `模型_三视图.pdf`。图内有模型名、三个中文视图名称和 `第一角法｜三视图同比例｜仅供外形参考，不用于加工或量测`。不标 `1:1` 或绝对打印比例。长文件名不挤占图形。

**第一角法：** 右视是“从物体右侧观察”，画在前视左方；顶视画在前视下方。前/顶共用竖直中心线，前/右共用水平中心线。更换正面只改变观察方向，不改变纸上位置。

| 左栏 | 右栏 |
| --- | --- |
| 右视 | 前视 |
| 模型名、投影法和用途说明 | 顶视 |

## 3. 投影、渲染与隔离

**方向不能镜像。** 下列方向指从模型中心指向相机。设前视方向为 `F`；向上 `U` 默认取 `+Z`，当 `F` 是 `±Z` 时取 `+Y`；右向 `R = U × F`（右手叉积）。相机都看向整体模型中心：前视 `(方向 F, 上 U)`，顶视 `(方向 U, 上 −F)`，右视 `(方向 R, 上 U)`。默认结果必须匹配查看器：前 `−Y / +Z`、顶 `+Z / +Y`、右 `+X / +Z`。默认右视中模型的 `+Y` 特征应位于图像右侧。禁止通过事后翻图来拼版。

**同一长度在三张图上必须一样长。** 以整体 `boundsMm` 中心为共同原点，把包围盒八角投影到各视图。先扣除标签和留白，再分别计算每个视图非零宽高对应的 `可用像素 / 投影毫米`；全部候选值的最小值就是唯一的 `px/mm`。据此设置各 `OrthographicCamera` 视锥。单个方向厚度为零时不作除数；不能逐视图做 fit。长条、薄片、远离原点的装配均不得裁切或拆散。最终图纸不依赖屏幕尺寸或 DPR。

**看得清外形，但不假装是 CAD 线稿。** 建议用一个临时场景和渲染器顺序渲染三次，每次立即拷贝到合成画布。用白底、浅灰实体、深色可见边；靠实体和深度测试处理遮挡。无曲面边界的 STL 仍要能辨认外轮廓和前方特征。不要显示三角剖分线、选区或工具栏。

**不影响现有预览。** 只释放导出创建的几何、材质和渲染资源，不释放交互查看器的资源。导出绑定模型、质量与用户会话；模型切换、退出、取消或卸载后丢弃迟到结果。编码或 WebGL 失败要提示、可重试，不生成空白 PDF，也不触发云端保存。

## 4. 实施顺序

- [ ] **先验证几何。** 在 `src/lib/models/` 新增 `modelThreeViewExport.ts`，以纯函数计算方向、范围和共享比例。在 `src/lib/__tests__/modelThreeViewExport.test.ts` 先覆盖下表的数值与镜像用例，再接 Three.js。需要时仅提取默认方向常量，不重写交互查看器。
- [ ] **生成可检验的产物。** 生成函数接受解析模型、名称、前视方向和取消信号，返回 PDF `Blob`；不在函数内自动下载。调用方在下载前最后一次检查会话，可阻止旧模型文件误出。
- [ ] **接入模型页。** 在 `src/pages/ModelViewerPage.tsx` 接入确认、方向、导出中和错误状态。用 `src/lib/__tests__/modelViewerPage.test.tsx` 验证入口、取消、双击、换模型和重试，不改变原有保存流程。
- [ ] **验证真正下载的 PDF。** 扩展 `tests/e2e/model-viewer.spec.ts`，复用 `tests/e2e/model-fixtures.ts`；用自建非对称样件，经真实 Worker、WebGL 和浏览器下载。打开或栅格化下载所得 PDF 检查版面，不以 HTTP 成功或文件头代替。云端读取可沿用本地 HTTP 模拟，私有模型及样张不进 Git。

## 5. 验收矩阵

| 用例 | 判定标准 |
| --- | --- |
| 方向与镜像 | 用右侧面靠 `+Y` 端有凸台的非对称样件，检查下载的 PDF：默认右视凸台在画面右侧。换正面后三视图联动；至少覆盖一次从 `+Z` 或 `−Z` 观察。 |
| 同比与位置 | `X/Y/Z = 40/20/10 mm` 的长方体默认投影宽×高：前 `40×10`、顶 `40×20`、右 `20×10`。前/顶等宽，前/右等高。按最终合成图像素测量，共享长度和中心线允许约 2 px 抗锯齿误差。 |
| PDF 版面 | 真正导出的是 A4 横向单页；三个视图区非空，中文可读，无截断或重叠。正对圆孔或圆柱端面时圆不变椭圆；后方遮挡特征不透出。 |
| 数据来源与单位 | 一份模拟私有云端 `ready` STEP 经过真实解析后导出；一份未保存的本地 STL 也能导出。用已知非毫米 STL 校验导出所用包围盒的毫米值，只换算一次；仅凭自适应图片不能证明单位正确。单独监测导出动作，无原文件重下载、上传、数据库写入或公开 URL。 |
| 边界与回归 | 长薄模型、多网格、无曲面边界可出图；尚无有效模型或正在切换质量不可导出。双击仅下载一次，换模型/退出无迟到下载，失败后能重试。导出前后交互视角、背景和选区不变。 |

**实施后的门禁（PowerShell，项目根目录）：** 对本次全部新增、修改的代码文件执行 `npx eslint --max-warnings=0` 并列出实际文件路径；执行 `npx tsc -b`、`npm test`、`npm run build`，再运行 `npx playwright test tests/e2e/model-viewer.spec.ts`。浏览器测试前确认没有复用旧的 preview 服务。报告实际结果，区分合成样件、模拟云端和真实云端；没有真实账号或样件授权则明确标为未验证，不写生产数据。按 `AGENTS.md` 仅提交本任务通过验证的修改，不推送、不部署。

三视图浏览器用例要求 Poppler 的 `pdfinfo` 和 `pdftoppm` 在 `PATH` 中。测试会渲染实际下载的 PDF 整页，并把页面 PNG 留在 Playwright 测试产物中；Poppler 不属于应用运行时依赖。
