## 1. 已知事实与比较边界

- 用户截图显示嘉立创模型轮廓及曲面分界更清楚，我们的画布较小、页面信息较多，模型下部有可见分段感。
- 两张截图分别标为 `male_5(1).stp` 与 `male_5.stp`，相机朝向不同，尚未确认文件字节相同。不能根据这两张图断言模型形状解析错误。
- 本地 `male_5.stp` 通过当前引擎解析，输出 5,632 个三角形，与我方截图一致。输出包含 35 个 `brep_faces` 面分组，目前 Worker 未保留。
- 当前查看器使用导入法线和 `EdgesGeometry(geometry, 30)`。该算法提取锐角特征，不等于 CAD 曲面边界。
- `ModelViewer.tsx` 的 resize 每次将相机距离设为自动适配距离，会丢失用户的缩放。这是已确认的代码行为。
- 上一轮只读复验：6 个相关测试文件、33 项测试通过；相关 ESLint 0 错误/0 告警；`npx tsc -b` 通过。这是历史基线，实施后必须重跑。
- 项目已有部署记录。现有 E2E 云端写入由 HTTP 夹具模拟，PGlite 执行真实 SQL/RLS 但使用 Storage schema 夹具；不能把它们当作真实 Storage HTTP 端到端验收。

## 3. 相机与 resize 行为

### 决策

普通 resize 保持相机相对于模型的观察方向、target、up、position、zoom；只更新 renderer 尺寸与相机 aspect/projection。窄窗口可能裁掉部分内容，用户可点击“适配窗口”，不得暗中恢复默认缩放。

- 首次打开不同模型：自动等轴测适配。
- 点击“等轴测/前视/顶视/右视”：切换约定视角并适配。
- “重置视角”：回到默认等轴测并适配。
- 新增“适配窗口”：保持当前观察方向，target 回到模型中心并适配。
- 容器为 0 宽/高：跳过，恢复非零尺寸时完成首次必要适配；已完成初始化的实例不得重复初始化。
- 同一文件切换质量、背景、边线、列表展开/折叠或全屏：保持视角状态。
- 保留当前 Z 向上及顶视特殊 up 轴的 OrbitControls 重建修复，不重现缓存 up 轴问题。

### 代码边界

修改 `src/components/models/ModelViewer.tsx`、`src/lib/models/modelView.ts`。将依赖 `model` 的整套场景重建拆成必要的资源更新：新几何替换并释放旧几何，显示选项更新不销毁 renderer。可以使用组件内部 helper，无需创建通用场景管理框架。

新增 viewer props：`modelKey: string | null` 用于标识当前原文件查看会话，同一文件换质量不变、新文件/新打开操作更新；它独立于云端 modelId。同一 key 更换 model 时保存相机姿态，不让 React key 强制重挂载。

## 4. STEP 显示质量

### 类型与参数

在 `modelTypes.ts` 增加：

```typescript
type ModelQuality = 'standard' | 'fine';
// 公共项：linearUnit='millimeter', linearDeflectionType='absolute_value'
// standard: linearDeflection=0.05, angularDeflection=0.3
// fine: linearDeflection=0.02, angularDeflection=0.2
```

`parseModel` options 与 `ParseRequest` 显式携带 `quality`；Worker 从固定配置映射取得参数，不接收任意用户数值。STL 使用原始网格，不提供无效的质量切换，也不把重新计算法线当成增加曲面精度。

### 页面行为

- 默认“标准”，STEP 可选“精细”。标签为“显示质量”，不要暗示它改变原文件精度。
- 选中精细后开始新的解析任务，保留当前网格可见，显示“正在生成精细预览…”。取消/超限/失败时保留原网格并恢复已生效档位；允许重试。
- 区分 requestedQuality 和 appliedQuality，不能请求失败后仍显示“精细已生效”。
- 快速切换档位时取消旧任务并隔离迟到结果。退出登录、换文件、换云端模型时同样隔离。
- 显示优化不能复用“打开新文件”的全量清空逻辑。保留 file、source unit、saveSession、recovering、保存状态和 URL modelId。
- 为简化互斥，保存期间禁止质量切换；质量解析期间禁止开始保存/恢复。解析完成后原保存状态原样恢复，已保存模型不会变成待保存。
- 已保存记录的 bounds_mm 不随质量修改；页面展示本次解析的近似尺寸。原文件和单位未变，因此不重新建记录。
- 每次最多保留当前显示网格与一个正在解析的任务，不做多档结果无限缓存。

## 5. STEP 曲面边界

### 数据契约

在 `ParsedMesh` 上增加可选 `surfaceEdges?: Float32Array`，每连续 6 个数为一条线段的两个端点，与 positions 使用同一坐标系与单位。它属于网格派生显示数据，不持久化到数据库。

解析引擎结果增加 `brep_faces?: { first: number; last: number; color?: unknown }[]` 的受控类型。核对 0.0.23 实现中的 first/last 为三角形索引且 last 包含端点，再实现提取；不得把它误当成顶点偏移。

建议新增 `src/lib/models/modelEdges.ts`，提供纯函数：

```typescript
function extractSurfaceEdges(
  mesh: Pick<ParsedMesh, 'positions' | 'indices'>,
  faces: readonly { first: number; last: number }[],
): Float32Array;
```

### 提取策略与限制

1. 校验每个面范围为整数、有序且不越界；缺失或不合法时不阻止实体显示，改用已有特征边并给出非阻断提示。
2. 面内按顶点索引构建无向三角边，消除同一面内部共享边，保留边界候选。不能把所有三角形边输出到画布。
3. 面内不要先按坐标合并重复顶点，以免把周期曲面的缝合边全部消掉。候选产生后再按端点位置去重重复线段。
4. 坐标去重容差按 mesh 尺度计算：`max(1e-7, diagonalMm * 1e-8)` mm，端点无向排序；验证毫米级小间隙不被吞并。大型离原点模型受 Float32 精度限制，不能宣称该容差能恢复已丢失的几何信息。
5. 仅在同一 mesh 内去重，避免混淆装配中不同实体的重合边。只合并端点一致的线段，不声称已解决不同分段方式的全部重叠。
6. 必须在 Worker 内提取，加入 Transferable；normalizeMeshes 校验线段长度与有限数值并按同一单位转换。不要在 UI 主线程上新增全模型复杂拓扑处理。
7. 边界提取沿用总解析超时；增加累计 300,000 条输出边界线段的显示预算，超过时禁用该模式并回退特征边、说明原因，实体网格仍可预览。此限制同样不能保证导入阶段峰值内存。

### 显示行为

- 显示模式统一为“无边线 / 特征边 / 曲面边界”，避免同时叠加两套线产生重影。
- STEP 有有效边界时默认“曲面边界”；STL 或缺失面信息时默认“特征边”，禁用不支持的曲面边界选项并说明。
- 保持深度测试，不透视显示背面隐藏线；用合理 polygonOffset 或其他已验证方式降低共面闪烁，不关闭 depthTest 掩盖问题。
- 边线颜色随背景调整，但不对每个三角形描边。
- 面的网格边界可能包含接缝，精细程度受离散网格影响。详情文案为“曲面边界为模型网格派生线，仅供查看”，不称为精确 CAD 拓扑边。
- 必须检查 male_5 的孔口、圆环、相切曲面与接缝；若只靠面分组不能稳定复现某条线，报告限制，不能伪造线条或无依据修改原形状。

## 6. 材质、背景与页面布局

### 渲染风格

- 增加“浅色 / 深色”背景，默认浅色，仅作用于当前查看器，不更改全局主题。
- 初始调试方向：中性浅灰材质、metalness 0、roughness 0.65–0.8；降低当前半球光/主光组合带来的泛白，适度补光显示孔壁。最终数值以同一文件同视角截图验证为准，不机械照搬。
- 显式确认当前 Three.js 的输出色彩空间、tone mapping 与 exposure 配合，不引入重复 gamma 校正。保留合理抗锯齿和 DPR 上限 2。
- 继续使用 CAD 导出的法线；禁止全局跨面合并法线把锐角抹平。
- 本期不引入外部 HDR 下载、SSAO、阴影流水线或复杂后处理。先用现有灯光和材质获得清晰形体。

### 页面布局

- 保留应用顶部统一导航，将页面内重复大标题与说明压缩为文件工具条。主要操作仍为“选择文件 / 保存到云端”。
- 右侧“本人云端模型”默认展开，可折叠；折叠后不卸载或清空查看器。不要修改全局侧栏组件的布局机制。
- 增加“全屏查看”，对包含工具栏、画布、必要状态提示的 viewer 容器调用 Fullscreen API；Esc 退出，监听 fullscreenchange 同步按钮状态。拒绝/不支持时提示，正常页面仍可用。
- 保存状态、文件名、包围盒尺寸保留可见；三角形/网格数、引擎限制、单位说明和网格精度提示收进可展开“模型详情”。STL 用户单位选择仍需可见且语义明确。
- 工具栏使用“边线”等用户用语；技术解释放 tooltip 或详情。
- 标准视角按钮明确当前状态；用户手动旋转后标为自由视角。程序调用 controls.update 不应立即清除刚选的标准视角；缩放和平移也不应被误判为旋转。
- 1440×900、1024×768 下按钮不溢出、退出全屏可见；画布不能被列表或详情挤成零高。更窄视口允许布局换行与列表收起。
