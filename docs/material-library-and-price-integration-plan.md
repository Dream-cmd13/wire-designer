# 物料库重构与价格一体化方案（方案2：多品类 Tab 物料中心）

## 1. 背景与改造目标

### 1.1 现状与痛点
1. **概念与功能重叠（伪双库）**：
   - 当前系统的左侧菜单包含“正式库”，其下挂载“数据库连接器”和“线束库”。
   - 现有的“线束库 (`/library/harnesses`)”仅仅是将当前用户保存的工程图纸项目（`projects`）重新过滤展示了一遍，其数据与能力与“首页（项目中心）”完全重叠。
2. **分类范畴错位**：
   - 在线束工程软件中，“图纸/工程项目”属于设计成果，而“连接器/导线/模具”属于基础物料（Master BOM Data）。两者混在“正式库”下导致层级混乱。
3. **物料属性与价格长期割裂**：
   - 物料的采购价格保存在数据库 `material_prices` 表中，但用户只能在具体图纸的“报价核算”弹窗深处查看或导入价格；
   - 工程师在选型查阅元器件规格时，无法知晓成本，无法做到“边看参数边比价”。

### 1.2 方案核心目标
1. **精简架构**：彻底移除冗余的“线束库”，左侧主菜单取消“正式库”，直接设立一级扁平入口 **【物料库】**。
2. **多品类覆盖**：建立多品类 Tab 结构，将散落在系统各处的连接器、线缆导线（电子线/护套线）、成型模与辅材集中归口展示。
3. **规格与价格精准匹配**：在物料列表右侧基于 `materialPriceTierKey` 关联匹配 `material_prices`，实时显示含税单价与计价单位。线材支持多长度档位清晰罗列（元/条），避免误以为是米价或单档覆盖。
4. **全量补价与维护闭环**：在物料库页面顶部提供“导出价格表”与“导入价格表”快捷入口。导出时包含 Catalog 全量物料（含未定价物料），直接支持离线批量补价与系统级更新。

## 3. 物料库页面结构与交互设计

页面采用标准物料中心布局，包含：**顶部全局操作栏**、**品类 Tab 切换**、**多维属性筛选栏**、**属性与价格综合列表**。

```
+-------------------------------------------------------------------------------+
| 物料库                                             [ 导出价格表 ] [ 导入价格表 ] |
| 标准元器件工程规格与采购价格总览                                                 |
+-------------------------------------------------------------------------------+
| [ 连接器 (128) ]   [ 线材 (45) ]       [ 模具与套管 (16) ]                         |
+-------------------------------------------------------------------------------+
| [ 搜索名称/型号/厂商... ]  [ 厂商下拉 ]  [ 系列下拉 ]  [ 屏蔽下拉 ]  [ PIN数下拉 ] |
+-------------------------------------------------------------------------------+
| 名称/型号      | 厂商/系列 | 类型/PIN | 关键工程规格         | 含税单价   | 计价单位 |
|----------------|-----------|----------|----------------------|------------|----------|
| DT06-2S-CE06   | DEUTSCH   | 插座 2P  | IP68 · 250V · 13A    | ¥ 3.20     | 元/个    |
| 1-967616-1     | TE        | 公端 4P  | IP67 · PA66          | ¥ 1.85     | 元/个    |
| UL1007 22AWG黑 | 标称线材  | 电子线   | 300V · 80℃ · OD1.6mm | 0.5m:¥1.80 | 元/条    |
|                |           |          |                      | 1m:  ¥2.50 |          |
+-------------------------------------------------------------------------------+
```

### 3.1 Tab 1：连接器（Connectors）
- **数据源**：`useCatalogStore` 的 `snapshot.connectors`。
- **关联价格**：基于 `kind: 'connector'`、`resourceId` 与标准规范 `specification` 精确匹配 `material_prices`。
- **筛选维度**：模糊搜索（名称/型号/系列/厂商/ID）、厂商过滤、系列过滤、屏蔽状态、类型（公头/母头/插座）、PIN 脚数、价格状态（全部/已定价/待定价）。
- **展示列**：
  1. 连接器名称与型号
  2. 厂商与系列
  3. 类型 / 屏蔽状态
  4. PIN 数 / 间距
  5. 电气与防护等级（耐压、额定电流、防护等级 IP、阻燃、温区）
  6. 材质
  7. **含税单价**（已定价显示绿色金额，未定价显示灰色“待定价”）
  8. **计价单位**（`元/个`）

### 3.2 Tab 2：线材（Wires）
- **数据源**：`useCatalogStore` 的 `snapshot.wires`（包含电子线 ElectronicWire、护套线 JacketedWire）。
- **关联价格**：基于 `kind: 'wire'` 与线材 `specification` 精准匹配。
- **多档位呈现**：支持一物料多长度档位完整呈现（例如 `0.5m: ¥1.80`、`1m: ¥2.50`），单位明确标注为 **`元/条`**。
- **筛选维度**：模糊搜索（线缆名称、型号、UL 标号、AWG 线规）、线种类型（电子线 / 护套线）、AWG 规格、屏蔽状态、价格状态。
- **展示列**：
  1. 线缆名称与型号
  2. 线种类型与 UL 标号
  3. 导体规格（AWG 线规、截面积 mm²、导体材质）
  4. 芯数与屏蔽
  5. 护套与绝缘（外径 OD、绝缘材质）
  6. 耐热耐压（额定电压、工作温区、阻燃级别）
  7. **参考单价与档位**（列出该线材维护的所有线长档位及单价）
  8. **计价单位**（`元/条`）

### 3.3 Tab 3：模具与辅材（Accessories & Overmolds）
- **成型外模**：展示直头成型与 90° 弯头成型、硬度、材质，价格关联自共享价格库（`元/个`）。
- **防护套管**：展示系统标准套管辅材（波纹管、热缩管等），并明确标注为系统标准配置价（`元/米`）。

## 4. 价格联动与管理机制

### 4.1 独立 Catalog 候选生成与精准索引
物料中心解耦对当前工程画板的依赖，通过 `getCatalogPriceCandidates(catalog)` 生成纯粹的 Catalog 全量报价物料基准。
利用 `materialPriceTierKey` 建立精准索引，对同物料多档位进行聚合，确保价格查询绝不串行、绝不覆盖。

### 4.2 导出价格模板（支持全量补价）
导出逻辑由 `buildCatalogPriceTemplateRows(snapshot, sharedPrices)` 驱动：
1. 包含当前 Catalog 中的全部物料；
2. 价格库已有记录的（包括线材的所有历史维护档位），自动回填当前单价；
3. 价格库尚未定价的，自动保留空单价行供采购/工艺批量补价；
4. 导出前严格校验 PriceStore 的读取状态，若读取异常明确阻断并提示用户，避免导出空数据。

### 4.3 批量导入更新
用户修改价格 Excel 后，直接在物料库页面上传：
1. 采用 `getCatalogPriceCandidates(snapshot)` 作为权威匹配集合，支持线材长度自动提取；
2. 校验成功后弹出确认面板，用户点击【确认写入共享价格库】后保存至 Supabase `material_prices`；
3. 物料库与所有工程的报价核算模块即时同步生效。
