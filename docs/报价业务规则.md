- 自动报价页按单价询价导出，不包含未确认的订单数量和订单总价；设计器订单报价保留用户填写的数量及总价。

## 1. 适用范围

- 当前工艺规则仅适用于 M 型连接器中的 M8、M12 线束。
- 外模必选，不提供“无外模”；内模可选，可选择“无内模”。当前外模仅黑色 PVC 45P 支持正式报价，TPE 仍待支持。
- 单头（A 端连接器、B 端切断或剥皮沾锡）固定使用 1 个外模，内模可为 0 或 1 个；双头（A/B 两端均为连接器）固定使用 2 个外模，内模可为 0 或 2 个。双头禁止仅一端有外模或内模。
- 内模继续作为外模的附属配置，不提供独立内模。单头支持“1 个外模、无内模”“1 个外模、1 个内模”；双头支持“2 个外模、无内模”“2 个外模、2 个内模”。
- 自动报价的成型数量随端部形式自动确定，不再手工选择“仅 A 端成型”。材料费、成型工费、图纸 BOM 和报价导出采用一致的实际数量；不使用内模时不计内模材料费与成型点数，SR 不计材料费或成型加工费。
- 自动报价以 A 端连接器为基准：B 端选连接器时，其针数须与 A 端一致，线材芯数也须与 A 端针数一致；三者屏蔽属性必须一致。切断或剥皮沾锡端不选择 B 端连接器，但线材仍须匹配 A 端。
- 更换 A 端后，保留仍匹配的 B 端和线材，否则自动选择匹配项；没有匹配物料时留空并阻止报价。连接器屏蔽属性未维护时须先补全目录，不能按非屏蔽处理。
- 一个产品只允许使用一根实体线材，不允许多根线材；一根多芯线仍是一根实体线材。
- 按单根线材长度判断：长度不超过 5 米（包含 5 米）时自动报价。超过 5 米需要人工核价，第一版仅提示“超过 5 米，需人工核价”，不自动出价；人工核价录入流程留到后续实现。
- “头”指连接器端：单头按 1 个焊接成型端，双头按 2 个焊接成型端；单头 B 端剥皮沾锡时，另计 1 个沾锡端。
- 先计算一整条成品的单价，再乘订单数量得到总价。
- 第一版保持简单，不将此前讨论过的复杂审批、订单、库存或价格版本体系作为已确认需求。

## 2. 材料范围、价格及单位

| 项目 | 第一版计价规则 | 价格来源及说明 |
| --- | --- | --- |
| 连接器 | 元/个；各连接器单价乘实际使用个数后求和 | 后续 Excel 导入含税价 |
| 线材 | 元/条；每个产品使用 1 条 | Excel 中规格包含长度，同规格不同长度分别提供整条含税价格；不可将元/条价格乘以米数 |
| 外模（黑色 PVC 45P） | 元/个；各外模单价乘实际使用个数后求和 | 后续 Excel 导入含税价 |
| 内模料（低密度透明 PE） | 元/个；各内模单价乘实际使用个数后求和 | 从共享价格库独立匹配，当前直头与弯头内模均为 0.30 元/个 |
| SR | 不计材料费和成型费 | SR = Strain Relief，应力缓解/尾套/护套 |
| 袋子、纸箱等包装材料 | 不单独计入材料成本 | 已包含在运费中 |
| 其他辅材 | 第一版暂不计入 | 包括此前提到的其他胶料、热缩管、波纹管、号码管、标签等；已明确计价的外模仍按上表处理 |

内模材料费与成型工费分别计算；SR 不参与计费。以外模和内模材料单价均为 0.30 元为例：仅外模为 0.30 + 0.20 × 1 = 0.50 元/端；内外模都有为 0.30 + 0.30 + 0.20 × 2 = 1.00 元/端。材料单价仍以价格库为准，不固定写死。

“热缩编织”是加工工艺，仍需计加工费；第一版暂不计其他辅材，不取消该工艺费用。包装材料已含在运费中，包装人工仍按第 3 节线长档位单独计费。

连接器、线材、外模和内模价格须从共享价格库匹配，缺价不能视为 0 元。内模价格与外模价格分别维护，不在报价代码中固定单价；SR 材料费按 0 元处理。

线材选价必须同时匹配规格和长度。例如同规格的 0.6 米线材与 1 米线材分别使用各自的整条价格，不根据其中一个价格按长度比例推算另一个价格。

## 3. 工艺单价和点数

以下费用均计算一整条成品的加工成本。芯数、加工端数和所需成型项目共同决定点数。第一版按线材全部标称芯数加工，不考虑只加工部分芯线的情况。

| 工艺 | 单价 | 计数规则 |
| --- | --- | --- |
| 裁线 | 0.05 元/半米 | 按单根线材长度，每半米向上取整；0.6 米按 2 个半米计 |
| 去皮 | 0.05 元/点 | 按各加工端的芯数累计点数；4 芯双头为 8 点 |
| 沾锡 | 0.05 元/点 | 仅 B 端选择剥皮沾锡时计费，按全部芯数；屏蔽线额外加 1 点 |
| 去外皮 | 0.05 元/点 | 按加工端数；双头为 2 点 |
| 处理编织 | 0.10 元/点 | 屏蔽线自动计算，按加工端数；双头为 2 点 |
| 热缩编织 | 0.10 元/点 | 屏蔽线自动计算，按加工端数；双头为 2 点 |
| 焊接 | 0.20 元/点 | 非屏蔽线每端按全部芯数计点；屏蔽线每端另加 1 个编织网焊接点。4 芯双头非屏蔽为 8 点、屏蔽为 10 点 |
| 成型 | 0.20 元/点 | 每个连接器端的外模、内模各计 1 点；仅外模为 1 点，内外模为 2 点；SR 和沾锡端不计成型 |
| 电测 | 按下表线长档位 | 一整条成品计 1 次 |
| 外观 | 按下表线长档位 | 一整条成品计 1 次 |
| 包装人工 | 按下表线长档位 | 一整条成品计 1 次 |

三项工价（元/条）保存在 `pricing_settings.settings.finishingLaborRates`，按实际线长向上匹配，不受芯数、端数影响。以下为初始价格，可在定价参数页面编辑并保存，也支持 JSON 导入导出：

| 线长范围 | 电测 | 外观 | 包装人工 |
| --- | --- | --- | --- |
| 0 < L ≤ 0.5 米 | 0.05 | 0.05 | 0.05 |
| 0.5 < L ≤ 1 米 | 0.10 | 0.20 | 0.10 |
| 1 < L ≤ 2 米 | 0.10 | 0.20 | 0.20 |
| 2 < L ≤ 3 米 | 0.10 | 0.20 | 0.20 |
| 3 < L ≤ 5 米 | 0.10 | 0.20 | 0.30 |

例如 0.6 米使用 1 米档，4 米使用 5 米档；超过 5 米仍需人工核价。

`finishingLaborRates` 以毫米档位 `500`、`1000`、`2000`、`3000`、`5000` 为键，每档包含 `电测`、`外观`、`包装人工` 三个十进制字符串价格（非负、最多六位小数）。`laborRates` 包含八项工艺（含新增沾锡），移除原三项统一单价。数据库保存函数校验全部档位，保留权限、版本冲突检测和审计；报价从数据库快照读取价格，配置缺失或无效时拒绝报价。

设线长为 L 米，线材标称芯数为 c（每端均按全部芯数加工），连接器焊接端数为 w，沾锡端数为 t（仅 B 端明确选择剥皮沾锡时为 1），剥皮及屏蔽处理端数 n = w + t：

```text
裁线费 = ceil(L ÷ 0.5) × 0.05
去皮费 = c × n × 0.05
去外皮费 = n × 0.05

屏蔽线：
处理编织费 = n × 0.10
热缩编织费 = n × 0.10
焊接费 = (c + 1) × w × 0.20
沾锡费 = (c + 1) × t × 0.05

非屏蔽线：
处理编织费 = 0
热缩编织费 = 0
焊接费 = c × w × 0.20
沾锡费 = c × t × 0.05

成型费 =（外模点数 + 内模点数）× 0.20
电测费 = 线长档位电测单价
外观费 = 线长档位外观单价
包装人工费 = 线长档位包装人工单价
```

是否屏蔽影响的工艺为处理编织、热缩编织、焊接、沾锡。非屏蔽线不计处理编织和热缩编织。即使标称 5 芯线实际仅接入 4 芯，第一版去皮和焊接仍按 5 芯计费；屏蔽线在焊接端增加 1 个焊接点，在沾锡端增加 1 个沾锡点，不额外增加剥皮点数。A 端只计焊接和成型，不叠加沾锡；B 端沾锡时不计焊接、成型、连接器及模具材料。两端屏蔽处理的单价相同，处理编织与热缩编织分别为 0.10 元/端。剥皮长度不影响计价。

只有裁线加工费按半米向上取整，不能据此把线材采购成本也按半米向上取整。

## 4. 损耗规则

设 M 为一条成品的四项材料成本，P 为十一项工艺费合计：

```text
M = 连接器含税成本 + 线材含税成本 + 外模含税成本 + 内模含税成本

P = 裁线 + 去皮 + 去外皮 + 处理编织 + 热缩编织
    + 焊接 + 沾锡 + 成型 + 电测 + 外观 + 包装人工

材料损耗 = M × 0.03
加工损耗 = P × 0.05
```

- 材料损耗以连接器、线材、外模、内模四项成本为基数。
- 加工损耗以全部十一项工艺费为基数，包含电测、外观、包装人工。
- 损耗以金额附加计算，不再额外增加材料用量或重复对损耗金额计算损耗。
- 本规则替代前期“暂不考虑损耗”的约定。

## 5. 含税成本、毛利、运费及总价

按本次确认的业务口径，将材料和工艺费用及其损耗相加，得到产品含税成本：

```text
产品含税成本 C = M + 材料损耗 + P + 加工损耗
               = M × 1.03 + P × 1.05

产品含税售价 S = C ÷ 0.8

最终含税含运费单价 U = round2(S × 1.03)

订单总价 = round2(U × 订单数量)
```

`round2` 表示十进制四舍五入到两位小数。用户已确认金额保留两位小数；舍入顺序作为第一版处理约定：中间计算保留精度，先舍入最终含税含运费单价，再乘数量得到总价。页面展示中间金额时可保留两位，但展示值不回代计算。

- 内模材料成本计入 M；SR 材料成本为 0 元，其他辅材暂不计入。
- 毛利按 20% 目标计算，使用除以 0.8，不使用乘以 1.2。此为本次约定的含税金额计价口径。
- 不再额外乘 1.13，也不对材料先除以 1.13、再对工艺加税。此前出现过的此类公式不作为本版规则。
- 运费在产品含税售价计算完成后统一乘 1.03，包含包装材料费用。
- 暂时忽略大小件差异，大件也不使用 1.05 运费系数。
- 材料损耗和运费虽然均为 3%，但计算基数不同，必须分别计算。
- 未确认任何数量阶梯折扣或加急/交期系数，不能沿用当前前端示例规则。
- 最终单价与总价保留两位小数，按上述顺序舍入，保证报价单所示单价乘数量与总价一致。

## 6. 计算示例

工艺示例：0.6 米、4 芯屏蔽线、双头，两端都完成加工，每端均有外模和内模；SR 不计费。

| 工艺 | 计算 | 金额（元） |
| --- | --- | --- |
| 裁线 | 2 × 0.05 | 0.10 |
| 去皮 | 4 × 2 × 0.05 | 0.40 |
| 去外皮 | 2 × 0.05 | 0.10 |
| 处理编织 | 2 × 0.10 | 0.20 |
| 热缩编织 | 2 × 0.10 | 0.20 |
| 焊接 | (4 + 1) × 2 × 0.20 | 2.00 |
| 成型 | 2 × 2 × 0.20 | 0.80 |
| 沾锡 | 双连接器不沾锡 | 0.00 |
| 电测 | 1 × 0.10（1 米档） | 0.10 |
| 外观 | 1 × 0.20 | 0.20 |
| 包装人工 | 1 × 0.10（1 米档） | 0.10 |
| 工艺费 P 合计 | | 4.20 |

```text
加工损耗 = 4.20 × 0.05 = 0.210 元
含加工损耗的工艺成本 = 4.410 元
```

仅为演示总价公式，假设该产品连接器、整条线材、外模的含税成本合计为 10 元（不是实际目录价格），并按当前内模单价 0.30 元/个另加两个内模共 0.60 元：

```text
材料成本 M = 10 + 2 × 0.30 = 10.60 元
材料损耗 = 10.60 × 0.03 = 0.318 元
产品含税成本 = 10.60 + 0.318 + 4.20 + 0.210 = 15.328 元
产品含税售价 = 15.328 ÷ 0.8 = 19.16 元
含运费单价未舍入值 = 19.16 × 1.03 = 19.7348 元
最终含税含运费单价 = round2(19.7348) = 19.73 元
例如订单数量为 100 条：订单总价 = 19.73 × 100 = 1973.00 元
```

中间损耗、成本和售价均保留计算精度，仅对最终单价及订单总价按约定舍入。订单总价始终使用已舍入单价乘数量。

- **舍入顺序**：第一版采用先对最终单价四舍五入到两位，再乘订单数量的约定，详见第 5 节。

## 9. 第一版实现与价格导入约定

采用“Excel 导入 + 前端计算”，不新增数据库表。价格读写集中在 `src/repositories/priceRepository.ts`，后续可改为 Supabase 实现；计算模块不访问本地存储或数据库。本版不实现价格历史、审批、订单和人工核价录入。

### 9.1 价格模板

在报价面板下载当前设计的价格模板，填写后导入。工作表名称固定为“材料价格”，表头依次为：

| 物料类型 | 物料名称 | 规格 | 单位 | 含税单价 |
| --- | --- | --- | --- | --- |
| 连接器 / 线材 / 外模 | 系统物料名称 | 中文可读规格，线材末尾带长度 | 元/条或元/个 | 非负十进制金额 |

- 模板根据当前设计生成，通常只需填写含税单价。模板不包含内部 ID、物料标识或 JSON 数组；系统根据物料类型、名称、规格和单位自动关联已有目录物料，不因价格导入而新建目录或数据库记录。
- 规格使用普通文本和空格，例如 `PVC 4芯 24AWG 屏蔽 黑色 OD5mm 红色 黑色 绿色 白色 0.6m`。支持用英文逗号或中文逗号替换空格分隔，连续空格与英文大小写不影响匹配；不支持省略关键规格或任意模糊描述。
- 线长并入线材规格末尾，必须带单位，支持 `0.6m`、`600mm`、`0.6米`、`600毫米`；内部仍保存准确毫米数。不同长度可分别增加价格行，不按米数乘整条价。
- 匹配范围包括当前设计与已加载的目录。未匹配或同名同规格对应多个物料时整批拒绝，提示核对名称、规格或在目录中区分型号，不自动猜选。
- 线材须关联目录物料；自定义、未关联目录的线材缺少稳定标识，不能自动报价。
- 连接器和外模以目录标识及其规格匹配。线材先匹配目录标识、规格及单位，再选择不小于实际长度的最小价格档位；边界值使用当前档位。现有档位为 500、1000、2000、5000 毫米，例如 600 毫米使用 1000 毫米整条价。缺少可覆盖实际长度的档位或选中档位存在重复价时停止自动报价，不能按米数比例换算。超过 5000 毫米仍转人工核价。
- 项目保存实际长度；价格表 `length_mm` 表示线材价格档位上限。裁线加工费与超过 5 米的判断使用实际长度，不使用价格档位长度。
- 单价支持最多 9 位整数、6 位小数；最终报价金额仍四舍五入至两位。空价、负数、错误单位、重复键及公式单元格整批拒绝，不导入部分行；明确填写的 0 是有效采购价格，不等同于缺价。
- 模板最多 10000 条记录、5 列，文件不超过 5 MB。旧七列模板需重新下载；成本分析工作表只作为导出布局参考，不直接用作材料价格导入文件。
- 导入先预览数量及价格，再点击“确认合并”。同键更新，不同键新增，未涉及的原价格保留；保存失败不宣告导入成功。
- 价格统一保存在数据库 `material_prices` 表，含税单价字段为 `tax_included_price`，线长字段为 `length_mm`，物料关联字段为 `resource_id`。所有登录用户共享，可导入更新；未登录用户无权访问价格。
- 导入整批新增或更新，同键覆盖，未涉及的价格保留。旧浏览器 localStorage 价格不自动上传或继续参与报价。
- 下载按钮导出全部共享价格；空库时下载目录物料空白模板，线材长度可在规格末尾调整。进入面板、窗口重新获得焦点和导出前重新读取数据库，不依赖本机缓存。超过 10000 条的共享库导出后，应拆成每份最多 10000 条再导入。

### 9.2 加工信息与报价输出

- `quotation.processingEnds` 表示连接器加工端数，必须等于连接器个数（1 或 2）；`quotation.endpointBType` 保存 B 端形式。剥皮、剥外皮、屏蔽处理额外累计沾锡端，不按已连接芯线数量折减加工费。未选择 B 端形式的设计器项目按连接器个数确定单头切断或双头连接器。
- 外模点数读取画布外模个数，内模点数读取各模型的“包含内模”设置；第一版每端最多一个外模，材料仅支持目录中的黑色 PVC 45P。服务端校验外模数量必须等于加工端数（单头 1 个、双头 2 个），双头内模只能为 0 或 2 个，不满足时阻止报价及结果导出；设计器中编辑到一半的非对称配置可保留，但不能获得正式报价。
- SR 不计费，报价面板及导出不再展示 SR 点数。已有项目中的 SR 数据保留，不进入费用计算。
- 数量支持 1 至 1000000 的整数，自动报价线长采用正整数毫米。缺价、重复价、不支持的配置或未确认加工端数时，不显示和导出最终单价与总价。
- 展示材料、十一项工艺、损耗、含税成本、20% 毛利售价和 3% 运费。报价改为 Excel 导出，参考“成本分析-M12单线”的横向布局，一行代表一条成品的报价计算；另列订单数量和订单总价。
- 导出包括产品名称、连接器规格、含长度的线材规格、芯线颜色、外被材质、四项材料成本、两类损耗、十一项工艺、产品含税成本及售价、运费、最终单价和订单总价。未提供的防水等级、品牌或外部对比价不猜填。
- 成本分析导出是当前计算结果快照，不在 Excel 中重新计算，也不把原成本表的工艺费或售价公式带入；金额为数值，显示两位小数，中间值保留计算精度。价格不齐或超过 5 米时禁止导出。内部标识和 JSON 规格不出现在业务导出中。
- BOM 清单仅显示及导出物料用量，移除旧演示单价与金额；真实成本统一由报价面板展示，避免出现两套报价口径。

## 10. 剥皮沾锡计价上线步骤（2026-10-12）

- 自动报价支持 B 端“剥皮沾锡”；报价选择独立保存在 `quotation.endpointBType`，不虚构生产用剥皮长度。图纸为示意图。
- 4 芯屏蔽线 B 端费用为去皮 0.20 + 去外皮 0.05 + 处理编织 0.10 + 热缩编织 0.10 + 沾锡 0.25 = 0.70 元；A 端另外按焊接成型规则计算。裁线按整条线长计一次。
- 部署前备份 `pricing_settings` 的 settings、version 及当前函数定义，并保留当前前后端部署版本。执行 `supabase/updates/20261012_tinning_labor_rates.sql`（此前应已执行线长档位更新）。脚本保留现有数据、材料价格及其他参数，新增沾锡 0.05、去皮调整为 0.05，两项编织工价设为 0.10；仅首次新增沾锡时更新数据与版本，重复执行不覆盖后续人工调价。
- `npm run quote:build` 生成报价引擎；数据库更新、报价 Edge Function 和前端须作为同批版本发布，旧参数缺少沾锡项时新引擎会拒绝报价。代码修改或构建不等于线上部署。
- 如需回退，同时恢复备份的定价配置、保存函数定义及前后端版本；不清空业务表。

- 剥外皮单价更新：执行 `supabase/updates/20261012_outer_strip_rate.sql`，仅将去外皮从 0.02 调整为 0.05 元/端，保留其他参数；执行前备份定价记录，回退时恢复该字段并递增版本。
