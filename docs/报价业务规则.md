# M8/M12 线束报价业务规则（第一版）

更新日期：2026-09-09

本文汇总业务讨论中已确认的规则，作为报价功能后续实现与验收依据。第一版采用的处理约定及后续事项单独说明。当前前端报价公式、示例价格、数量折扣和交期系数均不代表实际业务规则，不能直接沿用。

## 1. 适用范围

- 当前工艺规则仅适用于 M 型连接器中的 M8、M12 线束。
- 一个产品只允许使用一根实体线材，不允许多根线材；一根多芯线仍是一根实体线材。
- 按单根线材长度判断：长度不超过 5 米（包含 5 米）时自动报价。超过 5 米需要人工核价，第一版仅提示“超过 5 米，需人工核价”，不自动出价；人工核价录入流程留到后续实现。
- “头”指加工端：单头按 1 端，双头按 2 端。
- 先计算一整条成品的单价，再乘订单数量得到总价。
- 第一版保持简单，不将此前讨论过的复杂审批、订单、库存或价格版本体系作为已确认需求。

## 2. 材料范围、价格及单位

| 项目 | 第一版计价规则 | 价格来源及说明 |
| --- | --- | --- |
| 连接器 | 元/个；各连接器单价乘实际使用个数后求和 | 后续 Excel 导入含税价 |
| 线材 | 元/条；每个产品使用 1 条 | Excel 中规格包含长度，同规格不同长度分别提供整条含税价格；不可将元/条价格乘以米数 |
| 外模（黑色 PVC 45P） | 元/个；各外模单价乘实际使用个数后求和 | 后续 Excel 导入含税价 |
| 内模料（低密度透明 PE） | 材料成本暂按 0 元 | 属于明确的第一版临时业务约定 |
| SR | 材料成本暂按 0 元 | SR = Strain Relief，应力缓解/尾套/护套 |
| 袋子、纸箱等包装材料 | 不单独计入材料成本 | 已包含在运费中 |
| 其他辅材 | 第一版暂不计入 | 包括此前提到的其他胶料、热缩管、波纹管、号码管、标签等；已明确计价的外模仍按上表处理 |

内模和 SR 的材料费为 0 元，不代表成型工艺免费：实际使用时仍按相应成型点数计加工费。

“热缩编织”是加工工艺，仍需计加工费；第一版暂不计其他辅材，不取消该工艺费用。包装材料已含在运费中，也不取消每条 0.20 元的包装人工。

材料价格尚待导入。除内模和 SR 外，未提供价格的材料不能依据本文认定为 0 元。

线材选价必须同时匹配规格和长度。例如同规格的 0.6 米线材与 1 米线材分别使用各自的整条价格，不根据其中一个价格按长度比例推算另一个价格。

## 3. 工艺单价和点数

以下费用均计算一整条成品的加工成本。芯数、加工端数和所需成型项目共同决定点数。第一版按线材全部标称芯数加工，不考虑只加工部分芯线的情况。

| 工艺 | 单价 | 计数规则 |
| --- | --- | --- |
| 裁线 | 0.05 元/半米 | 按单根线材长度，每半米向上取整；0.6 米按 2 个半米计 |
| 去皮 | 0.02 元/点 | 按各加工端的芯数累计点数；4 芯双头为 8 点 |
| 去外皮 | 0.02 元/点 | 按加工端数；双头为 2 点 |
| 处理编织 | 0.10 元/点 | 屏蔽线自动计算，按加工端数；双头为 2 点 |
| 热缩编织 | 0.10 元/点 | 屏蔽线自动计算，按加工端数；双头为 2 点 |
| 焊接 | 0.20 元/点 | 非屏蔽线每端按全部芯数计点；屏蔽线每端另加 1 个编织网焊接点。4 芯双头非屏蔽为 8 点、屏蔽为 10 点 |
| 成型 | 0.20 元/点 | 每端的外模、内模、SR 分别计 1 点；一端三者都有为 3 点，两端都有为 6 点 |
| 电测 | 0.05 元/整条 | 一整条成品计 1 次 |
| 外观 | 0.20 元/整条 | 一整条成品计 1 次 |
| 包装人工 | 0.20 元/整条 | 一整条成品计 1 次 |

设线长为 L 米，线材标称芯数为 c（每端均按全部芯数加工），加工端数为 n：

```text
裁线费 = ceil(L ÷ 0.5) × 0.05
去皮费 = c × n × 0.02
去外皮费 = n × 0.02

屏蔽线：
处理编织费 = n × 0.10
热缩编织费 = n × 0.10
焊接费 = (c + 1) × n × 0.20

非屏蔽线：
处理编织费 = 0
热缩编织费 = 0
焊接费 = c × n × 0.20

成型费 =（外模点数 + 内模点数 + SR 点数）× 0.20
电测费 = 0.05
外观费 = 0.20
包装人工费 = 0.20
```

是否屏蔽影响的工艺为处理编织、热缩编织、焊接。非屏蔽线不计处理编织和热缩编织。即使标称 5 芯线实际仅接入 4 芯，第一版去皮和焊接仍按 5 芯计费；屏蔽线每端另外增加 1 个编织网焊接点。

只有裁线加工费按半米向上取整，不能据此把线材采购成本也按半米向上取整。

## 4. 损耗规则

设 M 为一条成品的三项材料成本，P 为十项工艺费合计：

```text
M = 连接器含税成本 + 线材含税成本 + 外模含税成本

P = 裁线 + 去皮 + 去外皮 + 处理编织 + 热缩编织
    + 焊接 + 成型 + 电测 + 外观 + 包装人工

材料损耗 = M × 0.03
加工损耗 = P × 0.05
```

- 材料损耗只以连接器、线材、外模三项成本为基数。
- 加工损耗以全部十项工艺费为基数，包含电测、外观、包装人工。
- 损耗以金额附加计算，不再额外增加材料用量或重复对损耗金额计算损耗。
- 本规则替代前期“暂不考虑损耗”的约定。

## 5. 含税成本、毛利、运费及总价

按本次确认的业务口径，将材料和工艺费用及其损耗相加，得到产品含税成本：

```text
产品含税成本 C = M + 材料损耗 + P + 加工损耗
               = M × 1.03 + P × 1.05

产品含税售价 S = C ÷ 0.8

最终含税含运费单价 U = round2(S × 1.03)

订单总价 = round2(U × 订单数量)
```

`round2` 表示十进制四舍五入到两位小数。用户已确认金额保留两位小数；舍入顺序作为第一版处理约定：中间计算保留精度，先舍入最终含税含运费单价，再乘数量得到总价。页面展示中间金额时可保留两位，但展示值不回代计算。

- 内模、SR 材料成本当前均为 0 元，其他辅材暂不计入，因此未出现在上述简化公式中。
- 毛利按 20% 目标计算，使用除以 0.8，不使用乘以 1.2。此为本次约定的含税金额计价口径。
- 不再额外乘 1.13，也不对材料先除以 1.13、再对工艺加税。此前出现过的此类公式不作为本版规则。
- 运费在产品含税售价计算完成后统一乘 1.03，包含包装材料费用。
- 暂时忽略大小件差异，大件也不使用 1.05 运费系数。
- 材料损耗和运费虽然均为 3%，但计算基数不同，必须分别计算。
- 未确认任何数量阶梯折扣或加急/交期系数，不能沿用当前前端示例规则。
- 最终单价与总价保留两位小数，按上述顺序舍入，保证报价单所示单价乘数量与总价一致。

## 6. 计算示例

工艺示例：0.6 米、4 芯屏蔽线、双头，两端都完成加工，每端均有外模、内模和 SR。

| 工艺 | 计算 | 金额（元） |
| --- | --- | --- |
| 裁线 | 2 × 0.05 | 0.10 |
| 去皮 | 4 × 2 × 0.02 | 0.16 |
| 去外皮 | 2 × 0.02 | 0.04 |
| 处理编织 | 2 × 0.10 | 0.20 |
| 热缩编织 | 2 × 0.10 | 0.20 |
| 焊接 | (4 + 1) × 2 × 0.20 | 2.00 |
| 成型 | 3 × 2 × 0.20 | 1.20 |
| 电测 | 1 × 0.05 | 0.05 |
| 外观 | 1 × 0.20 | 0.20 |
| 包装人工 | 1 × 0.20 | 0.20 |
| 工艺费 P 合计 | | 4.35 |

```text
加工损耗 = 4.35 × 0.05 = 0.2175 元
含加工损耗的工艺成本 = 4.5675 元
```

仅为演示总价公式，假设该产品连接器、整条线材、外模的含税成本合计 M = 10 元（不是实际目录价格）：

```text
材料损耗 = 10 × 0.03 = 0.30 元
产品含税成本 = 10 + 0.30 + 4.35 + 0.2175 = 14.8675 元
产品含税售价 = 14.8675 ÷ 0.8 = 18.584375 元
含运费单价未舍入值 = 18.584375 × 1.03 = 19.14190625 元
最终含税含运费单价 = round2(19.14190625) = 19.14 元
例如订单数量为 100 条：订单总价 = 19.14 × 100 = 1914.00 元
```

中间损耗、成本和售价均保留计算精度，仅对最终单价及订单总价按约定舍入。不使用未舍入单价乘 100 后得到的 1914.19 元作为本例订单总价。

## 7. 第一版处理约定与后续事项

线材按条且规格包含长度、全部芯数加工、非屏蔽线焊接计点以及金额保留两位小数均已确认。

- **舍入顺序**：第一版采用先对最终单价四舍五入到两位，再乘订单数量的约定，详见第 5 节。
- **超过 5 米**：第一版提示需人工核价，暂不实现人工价格录入，也不显示自动计算的最终单价或订单总价。后续再确认人工提供的是加工费、产品含税售价还是含运费最终单价，并据此设计录入流程，避免重复加收费用。
- **真实价格导入**：待 Excel 提供后确认字段映射和缺价处理；价格未齐全不能认定具备真实报价条件。

## 8. 后续价格导入与实施边界

- 连接器、线材、外模价格后续通过 Excel 提供；本文不假定具体表头或导入文件格式。
- 导入时需要将规格与系统物料准确对应，并保留正确的含税计价单位。
- 内模、SR 暂按 0 元是明确例外，其他材料缺价时的处理需在导入和报价实现时明确。
- 本文规则用于实现与验收；首版实现约定见第 9 节。未修改数据库或导入真实价格。

## 9. 第一版实现与价格导入约定

采用“Excel 导入 + 前端计算”，不新增数据库表。价格读写集中在 `src/repositories/priceRepository.ts`，后续可改为 Supabase 实现；计算模块不访问本地存储或数据库。本版不实现价格历史、审批、订单和人工核价录入。

### 9.1 价格模板

在报价面板下载当前设计的价格模板，填写后导入。工作表名称固定为“材料价格”，表头依次为：

| 物料类型 | 物料名称 | 规格 | 单位 | 含税单价 |
| --- | --- | --- | --- | --- |
| 连接器 / 线材 / 外模 | 系统物料名称 | 中文可读规格，线材末尾带长度 | 元/条或元/个 | 非负十进制金额 |

- 模板根据当前设计生成，通常只需填写含税单价。模板不包含内部 ID、物料标识或 JSON 数组；系统根据物料类型、名称、规格和单位自动关联已有目录物料，不因价格导入而新建目录或数据库记录。
- 规格使用普通文本和空格，例如 `PVC 4芯 24AWG 屏蔽 黑色 OD5mm 红色 黑色 绿色 白色 0.6m`。支持用英文逗号或中文逗号替换空格分隔，连续空格与英文大小写不影响匹配；不支持省略关键规格或任意模糊描述。
- 线长并入线材规格末尾，必须带单位，支持 `0.6m`、`600mm`、`0.6米`、`600毫米`；内部仍保存准确毫米数。不同长度可分别增加价格行，不按米数乘整条价。
- 匹配范围包括当前设计与已加载的目录。未匹配或同名同规格对应多个物料时整批拒绝，提示核对名称、规格或在目录中区分型号，不自动猜选。
- 线材须关联目录物料；自定义、未关联目录的线材缺少稳定标识，不能自动报价。
- 连接器和外模以目录标识及其规格匹配。线材先匹配目录标识、规格及单位，再选择不小于实际长度的最小价格档位；边界值使用当前档位。现有档位为 500、1000、2000、5000 毫米，例如 600 毫米使用 1000 毫米整条价。缺少可覆盖实际长度的档位或选中档位存在重复价时停止自动报价，不能按米数比例换算。超过 5000 毫米仍转人工核价。
- 项目保存实际长度；价格表 `length_mm` 表示线材价格档位上限。裁线加工费与超过 5 米的判断使用实际长度，不使用价格档位长度。
- 单价支持最多 9 位整数、6 位小数；最终报价金额仍四舍五入至两位。空价、负数、错误单位、重复键及公式单元格整批拒绝，不导入部分行；明确填写的 0 是有效采购价格，不等同于缺价。
- 模板最多 10000 条记录、5 列，文件不超过 5 MB。旧七列模板需重新下载；成本分析工作表只作为导出布局参考，不直接用作材料价格导入文件。
- 导入先预览数量及价格，再点击“确认合并”。同键更新，不同键新增，未涉及的原价格保留；保存失败不宣告导入成功。
- 价格统一保存在数据库 `material_prices` 表，含税单价字段为 `tax_included_price`，线长字段为 `length_mm`，物料关联字段为 `resource_id`。所有登录用户共享，可导入更新；未登录用户无权访问价格。
- 导入整批新增或更新，同键覆盖，未涉及的价格保留。旧浏览器 localStorage 价格不自动上传或继续参与报价。
- 下载按钮导出全部共享价格；空库时下载目录物料空白模板，线材长度可在规格末尾调整。进入面板、窗口重新获得焦点和导出前重新读取数据库，不依赖本机缓存。超过 10000 条的共享库导出后，应拆成每份最多 10000 条再导入。

### 9.2 加工信息与报价输出

- 加工端数由用户在报价面板确认并随项目保存。第一版按一个连接器对应一个加工端，端数必须等于画布连接器个数（1 或 2），不按已连接芯线数量折减加工费。
- 外模点数读取画布外模个数，内模点数读取各模型的“包含内模”设置；第一版每端最多一个外模，材料仅支持目录中的黑色 PVC 45P。
- SR 暂无画布实体，通过报价面板选择 0 至加工端数的点数，初始为 0；使用 SR 时应填写实际点数。报价设置随项目配置保存，不单独建表。
- 数量支持 1 至 1000000 的整数，自动报价线长采用正整数毫米。缺价、重复价、不支持的配置或未确认加工端数时，不显示和导出最终单价与总价。
- 展示材料、十项工艺、损耗、含税成本、20% 毛利售价和 3% 运费。报价改为 Excel 导出，参考“成本分析-M12单线”的横向布局，一行代表一条成品的报价计算；另列订单数量和订单总价。
- 导出包括产品名称、连接器规格、含长度的线材规格、芯线颜色、外被材质、三项材料成本、内模/SR 零元材料、两类损耗、十项工艺、产品含税成本及售价、运费、最终单价和订单总价。未提供的防水等级、品牌或外部对比价不猜填。
- 成本分析导出是当前计算结果快照，不在 Excel 中重新计算，也不把原成本表的工艺费或售价公式带入；金额为数值，显示两位小数，中间值保留计算精度。价格不齐或超过 5 米时禁止导出。内部标识和 JSON 规格不出现在业务导出中。
- BOM 清单仅显示及导出物料用量，移除旧演示单价与金额；真实成本统一由报价面板展示，避免出现两套报价口径。
