# 成品图件号引出标注调整方案

## 1. 文档目的

根据目录 `D:\wire-harness-designer\wire-harness-designer图片备份` 中的参考图片，评估当前“成品图”在连接器、线材、外模等物料的 **BOM 件号引出标注** 方面需要做的调整，并给出可落地的实现方案。

本方案只针对当前成品图页面，不直接改造“制作图纸”工作台的另一套 `DrawingDocument` 渲染链路。

## 2. 参考图片观察

### 2.1 `成品图.png`

参考图尺寸约为 `969 × 178`，整体是横向线束总成图，主要特征如下：

- 左侧为 `P1` 连接器，带 PIN 位示意和“对插端”文字。
- 右侧为 `P2` 线材端。
- 线材上方有总长度标注：`*500±10`。
- 物料通过圆圈数字和引出线标识：
  - `①` 指向线材；
  - `②` 指向连接器/编织或外模区域；
  - `③`、`④` 指向连接器端不同零件区域。
- 件号圆圈位于总成图下方，避免遮挡连接器和线材主体。
- 引出线较细，视觉上弱于轮廓线和尺寸线。

### 2.2 `接线图.png`

- 标题为“接线图”。
- 使用 `P1`、`P2` 作为连接器端标识。
- 每一行表示 PIN 和颜色对应关系。
- 单端线束的另一端可以显示“切断”等状态。

### 2.3 `图纸图框.jpg`

- A4 横向图框，外框内有上、下数字分区和左右字母分区。
- 上方有合规说明区域。
- 下方为修订记录、比例、单位、审核/设计/制图信息、料号、图号、标题和公司信息。
- 中央区域应尽量保留为总成图、尺寸和接线图的主要工作区。

## 3. 当前实现与参考图的差异

当前实现主要位于：

- [`src/components/drawings/TwoDView.tsx`](../src/components/drawings/TwoDView.tsx)：成品图布局、图片组、接线图和 BOM。
- [`src/lib/productionDrawingLayout.ts`](../src/lib/productionDrawingLayout.ts)：BOM、总成图片和接线图的空间计算。
- [`src/lib/bom.ts`](../src/lib/bom.ts)：通用 BOM 分组和规格描述。
- [`src/lib/overmoldSpec.ts`](../src/lib/overmoldSpec.ts)：外模/内模 BOM 分组。
- [`src/lib/productImageExport.ts`](../src/lib/productImageExport.ts)：PNG/PDF 导出。

目前已经存在 BOM 表格中的圆圈序号，但它们只显示在 BOM 表格第一列，没有与上方实际图片建立引出关系，主要缺口如下：

1. 没有“BOM 行 → 实际物料实例”的稳定映射。
2. 没有覆盖在成品图上的 SVG 圆圈、引线和箭头层。
3. 当前总成图片与接线图之间只有很小间距，无法稳定放置参考图样式的件号圆圈。
4. BOM 行的生成逻辑分散在 `generateBOM`、`BOMTable` 和布局计数中，后续容易出现表格序号和图中序号不一致。
5. 当前导出依赖 `html2canvas`，新增标注必须位于同一个成品图世界层中，不能只在独立的 React 浮层中绘制。

## 4. 建议的目标形态

将功能定义为：

> **BOM 件号气泡引出标注层（BOM Item Balloon Callout Layer）**

目标结构：

```text
图框 SVG
  ↓
线束总成图片组
  ↓
尺寸标注 / P1、P2 标识
  ↓
件号气泡、引出线、箭头
  ↓
接线图
  ↓
BOM 表
```

建议默认自动生成标注，先不加入手动拖动气泡功能。这样图片组移动、BOM 行增删或规格变化后，标注不会产生过期坐标。

## 5. BOM 与图中目标的统一模型

建议新增一个生产图专用模块，例如：

```text
src/lib/productionBomRows.ts
```

该模块向 `BOMTable`、布局计算和件号引出层提供同一份行数据：

```ts
type ProductionBomRow = {
  key: string;
  itemNo: number;
  kind: 'wire' | 'connector' | 'outer-mold' | 'inner-mold' | 'accessory';
  name: string;
  specification: string;
  unit: string;
  quantity: number;
  targets: BomTargetRef[];
};

type BomTargetRef =
  | { kind: 'material'; id: string }
  | { kind: 'connector'; id: string }
  | { kind: 'model'; id: string }
  | { kind: 'sleeve'; id: string };
```

### 5.1 映射规则

| BOM 行类型 | 稳定分组键 | 图中引出目标 |
| --- | --- | --- |
| 线材 | 完整线材规格分组键 | 一个或多个 `material` |
| 连接器 | `resourceItemId` 或连接器型号 | 一个或多个 `connector` |
| 外模料 | 外模规格 ID | 一个或多个 `model` |
| 内模料 | 内模材质和外型规格 | 对应的 `model`，通过不同引线位置区分 |
| 保护套/热缩管等 | 完整附件规格键 | 一个或多个 `sleeve` |

`key` 必须稳定，不能使用 `itemNo` 作为身份。因为新增或删除 BOM 行时，后续序号会变化，但同一规格的物料仍应保持正确的目标关联。

### 5.2 重复物料

同一规格的多个连接器、线材或外模合并为一行 BOM 时：

- 默认显示一个件号气泡；
- 使用多条引出线指向多个实际实例；
- 当空间不足时，退化为指向一个代表实例，BOM 数量仍显示完整数量。

## 6. 标注定位与渲染方案

### 6.1 目标坐标

每个实际显示的图片卡片增加语义标识，例如：

```html
data-callout-kind="connector"
data-callout-id="connector-001"
```

通过图片卡片的 `getBoundingClientRect()` 获取真实显示区域，再根据 `world` 容器的变换换算为 `1200 × 800` 的图纸坐标。这样能够正确跟随：

- 图片加载后的真实尺寸变化；
- 图片组拖动；
- 成品图缩放和平移；
- 浏览器窗口尺寸变化。

连接器应优先绑定实际连接器图片，不绑定 PIN MAP 图片；外模绑定外模图片；线材绑定线材图片；保护套绑定保护套图片。

### 6.2 SVG 标注层

新增模块：

```text
src/components/drawings/ItemCalloutLayer.tsx
```

建议使用覆盖在成品图世界层上的 SVG：

- `viewBox="0 0 1200 800"`；
- 圆圈半径约 `10～12px`；
- 圆圈白底、黑色描边；
- 数字使用普通文本，支持 `1～99`，不依赖 `①～⑩` 字符表；
- **CAD 标准引出折线结构**：
  - 水平托线段（Horizontal Shelf）从气泡圆圈水平平伸至拐点 `(ex, by)`；
  - 倾斜指向段（Diagonal Leader）从拐点继续朝目标 `(tx, ty)` 延伸；
  - 水平段与倾斜段之间的转折内角严格保持为**钝角（> 90°，约为 115°）**，彻底避免锐角反向回折；
- 引线宽度约 `1～1.5px`；
- 箭头使用 SVG `marker-end`，精确指向目标内部/特征区域；
- 多实例物料支持由同一气泡发出多条引线分支。

引出层应放在图片组之后、BOM 表之前：

- 引线不会被图片遮挡；
- BOM 表可覆盖越界的引线；
- `html2canvas` 可以将其与成品图一起导出。

## 7. 版面需要调整的地方

### 7.1 增加件号引出带与接线图防遮挡

参考图的气泡位于总成图下方，而当前实现的接线图紧贴总成图片。在 [`productionDrawingLayout.ts`](../src/lib/productionDrawingLayout.ts) 增加：

```text
calloutBandHeight: 44px
calloutGap: 10px
```

布局关系调整为：

```text
总成图片
  ↓ 10px 间距
件号气泡 / 水平托线与钝角引出带（位于净空区域，所有引线斜向上延伸进图片）
  ↓ 10px 间距
接线图（完全置于气泡层下方，彻底避免遮挡）
```

新增空间应从 `maxImageHeight` 中动态扣除，不能让总成图、接线图或 BOM 越出图框。BOM 行数较多时，应优先缩小总成图片高度，而不是压缩件号气泡的可读性。

### 7.2 增加端点标识

参考图中的 `P1`、`P2` 和“对插端”是总成图的重要信息，建议：

- 在连接器图片组上方显示 `P1`、`P2`；
- 单端线束显示实际端点状态，例如“切断”；
- 文案从连接器和接线关系推导，不硬编码具体型号；
- 与接线图表头使用同一套端点名称来源。

### 7.3 保留尺寸标注空间

总长度尺寸应位于总成图上方，件号引出线不得穿过尺寸线。尺寸标注、端点标识和件号气泡应分别占用独立区域。

## 8. 自动布局规则

建议按以下顺序放置气泡：

1. 左侧连接器物料放在目标左侧或下侧。
2. 右侧连接器物料放在目标右侧或下侧。
3. 线材放在长线中段的下侧。
4. 外模放在外模图片外侧。
5. 多个气泡按 `itemNo` 顺序排列。
6. 避让 BOM 表、技术要求、标题栏、图框和其他气泡。
7. 目标图片移动后重新计算引线终点和折线路径。

布局模块可以采用“候选位置 + 碰撞检测”的简单算法：

- 为每个目标生成左、右、上、下四个候选气泡位置；
- 依次避让已有气泡和固定区域；
- 优先保留参考图中“总成下方”的位置；
- 无可用位置时再切换到总成上方或侧方。

第一版不要求解决所有引线交叉，只需保证引线不穿过 BOM、技术要求和标题栏，并且箭头目标明确。

## 9. 导出与交互要求

### 9.1 导出

由于当前 PNG/PDF 导出使用 [`productImageExport.ts`](../src/lib/productImageExport.ts) 的 `html2canvas`：

- 件号 SVG 必须放在 `data-drawing-world="true"` 容器内；
- 导出时保持 SVG 可见；
- 不需要额外绘制第二套 PNG/PDF 标注逻辑；
- 需要补充导出回归测试，确认 PNG 和 PDF 均包含圆圈、引线和箭头。

### 9.2 交互

第一阶段建议只支持：

- 显示/隐藏全部件号引出标注；
- 点击 BOM 行高亮对应的气泡和目标；
- 点击气泡高亮对应 BOM 行。

手动拖动气泡、隐藏单个气泡、修改引线折点可以作为第二阶段功能。

## 10. 测试与验收标准

### 10.1 纯逻辑测试

- BOM 行序号和目标映射一致。
- 同规格物料合并后只生成一个件号。
- 多实例物料能够生成多条引线或代表性引线。
- 外模和内模分组数量与 BOM 表一致。
- BOM 超过 10 项时仍能正确显示普通数字圆圈。
- 目标图片缺失时不崩溃、不生成错误箭头。
- 气泡位置不进入 BOM、技术要求和标题栏区域。

### 10.2 页面验收

- 成品图中可看到与 BOM 相同的件号气泡。
- ①/②/③ 等标注能够准确指向线材、连接器和外模。
- 拖动总成图片组后，引线仍然指向目标。
- 缩放和平移后，圆圈和箭头不发生错位。
- BOM 行数变化后，件号自动重新编号并同步更新。
- PNG、PDF 导出结果包含完整件号引出标注。
- 参考图中的 `P1`、`P2`、长度标注和接线图信息不被遮挡。

## 11. 实施优先级

### P0：必须完成

1. 统一生产图 BOM 行模型。
2. 增加 BOM 行到物料实例的稳定映射。
3. 增加 SVG 件号气泡、引线和箭头。
4. 增加件号引出带并调整总成/接线图间距。
5. 验证 PNG/PDF 导出。

### P1：建议完成

1. 增加 P1/P2 和端点状态标识。
2. 增加 BOM 行与气泡的双向高亮。
3. 增加重复物料的多引线布局。

### P2：后续增强

1. 手动拖动气泡。
2. 保存气泡位置和隐藏状态。
3. 单个气泡显示/隐藏。
4. 引线样式、编号格式和布局方向配置。

## 12. 结论

参考图最需要补齐的不是 BOM 内容，而是 **BOM 行与成品图物料之间的可视化关联**。推荐在当前 `TwoDView` 中新增自动生成的 SVG 件号引出层，并先统一 BOM 行数据和目标引用。

本方案可以复用当前图片组拖动、缩放和平移逻辑，也能自然进入现有 `html2canvas` 导出链路，改动范围小于直接重构 `ProductionDrawing` 对象系统，适合作为当前测试阶段的实现路径。
