# 线束设计器系统现有功能报告

报告日期：2026 年 11 月 9 日

2026 年 11 月 26 日补充：更新「制作图纸」工作台的实际用途。

核查版本：`dev` 分支，`d19be9e`

核查依据：当前工作区的页面入口、交互组件、业务计算、数据访问代码及本次测试结果。

## 一、系统定位与总体结论

本系统是一套面向线束业务的 Web 工具，覆盖物料选型、线束可视化设计、标准方案自动报价、BOM 输出、制作图纸，以及现有 DWG 图纸和 3D 模型的查看。

它可以帮助业务人员快速完成标准产品选配与核价，帮助工程人员表达接线关系、整理物料，并查询已有成品方案的成本依据。「制作图纸」工作台用于制作营销演示图。

当前已形成三条主要使用路径：

1. **快速报价**：选择端头、线材和模具 → 输入线长、数量 → 服务端核价 → 导出报价 Excel。
2. **设计与出图**：创建项目 → 编辑连接器和接线 → 查看 BOM、成品图 → 导出设计文件、清单和图纸。
3. **资料查看与演示**：查询物料及成品成本资料，制作二维营销演示图，查看 DWG 和 STEP/STL 文件。

项目约定当前处于准备上线阶段。本报告中的“已实现”表示当前代码存在对应入口与实现；不等同于已完成线上部署验收，也不代表所有物料数据都已由业务复核。

使用权限方面，业务员登录后进入自动报价页；项目设计、物料库、独立图纸、DWG 和 3D 等完整工作区面向工程师和管理员。未登录用户另外可使用独立制图的本地工具。

## 三、线束项目与可视化设计

### 3.1 项目管理

- 通过新建向导创建空白项目、简单双端线束、T 型分支线束或星型四端线束。
- 设置项目名称、描述，并选择模板所需的连接器与相关配置。
- 打开已有项目继续编辑，重命名或删除项目。
- 导出包含项目资料和完整设计内容的 JSON 文件，再通过导入入口创建可编辑设计。
- 导入时进行数据结构校验，并展示设计错误和警告数量。

项目保存按账号隔离，具备自动保存、保存状态反馈及本地恢复副本。其他设备成功保存了新版本时，旧窗口会进入冲突处理，允许保留本地副本、读取云端版本或另存新项目。

### 3.2 可视化配置

| 设计对象 | 当前可配置内容 |
| --- | --- |
| 连接器 | 从目录选型、更换型号、设置标识与位置、复制、调整连接方向 |
| 线材 | 选择目录物料或编辑规格，设置长度、颜色、AWG/截面积、芯数、屏蔽与 UL 等属性 |
| 端部加工 | 配置剥皮端、剥皮长度，以及沾锡或打端子等处理信息 |
| 接线关系 | 将线材端点连接到连接器 PIN，编辑多芯线接线明细，断开或删除接线 |
| 短接 | 为连接器配置多个 PIN 之间的短接关系 |
| 保护套 | 配置套管类型、长度、覆盖的线材；波纹管可设置材质和端部固定信息 |
| 外模 | 从目录选择外模规格，按可用规格配置内模 |
| 标识附件 | 添加、修改或删除线材标签和号码管 |

画布支持节点拖动、缩放、平移、右键操作、撤销重做和只读锁定。删除会影响接线的对象时，界面提供相关提示。

设计文件导入导出所用的校验逻辑可以检查 PIN 越界、无效连接器引用、自连接、连接侧冲突、短接配置、芯线索引、保护套绑定、重复标识和数量等问题。该校验属于设计数据与连接关系检查，不覆盖电气仿真、电流承载或全部制造规则。

### 3.3 BOM 与成品图

**BOM 清单**用于汇总当前项目物料、规格和用量，支持 CSV、Excel 导出，并提供关联文件查看入口。

**成品图**是设计器内的二维工程表达页面，可展示目录物料图片、接线表、BOM、件号气泡和引出线、尺寸及图框信息。用户可编辑图框与签审资料、调整相关布局，并导出 PNG 或 PDF。

成品图依赖目录中已配置的二维图片；缺少图片时会提示。其表达方式基于图片、接线和标注组合，并非自动生成实体三维线束或精确机械投影。

## 四、自动报价与定价管理

### 4.1 快速选配报价

自动报价页提供独立于完整设计流程的选配表单：

1. 选择 A 端 M12 连接器。
2. 选择 B 端连接器、切断端或剥皮沾锡端。
3. 根据 A 端的芯数和屏蔽属性筛选匹配的 B 端连接器及护套线。
4. 选择黑色 PVC 45P 外模，并按可用规格选择低密度透明 PE 内模。
5. 输入线长及订单数量，查看实时核价结果与配置预览。

线束设计器内也有报价入口，使用同一服务端报价链路。报价结果包含含税含运费单价、订单总价和核价时间；内部成本明细按角色返回。用户可重新核价，页面会提示单价变化。

支持导出对外报价 Excel；工程师和管理员还可导出内部成本分析 Excel。导出使用当前已显示的核价快照，包含所选配置与核价时间；内部表还包含定价版本和成本明细。

### 4.2 当前计价内容

| 成本类别 | 当前计算内容 |
| --- | --- |
| 主要材料 | 连接器、整条线材、外模、内模 |
| 加工工艺 | 裁线、去皮、去外皮、处理编织、热缩编织、焊接、成型、沾锡 |
| 后道人工 | 电测、外观、包装人工，按线长档位匹配 |
| 附加因素 | 材料损耗、加工损耗、目标毛利率、运费率 |

计算关系为：

```text
产品成本 = 材料金额 + 加工金额 + 材料损耗 + 加工损耗
含税售价 = 产品成本 ÷ (1 - 目标毛利率)
含税含运费单价 = 含税售价 × (1 + 运费率)，四舍五入至两位小数
订单总价 = 上述单价 × 订单数量
```

价格与参数取自服务端数据库快照，物料规格也会由服务端根据目录重新确认。当前线材按整条价格计价，选择不小于实际长度的最小匹配价格档位，不按米数再次相乘。

### 4.3 报价的明确边界

- 当前可用的自动报价方案限一根实体护套线，搭配一个或两个 M12 连接器。
- 当前物料目录仅有 M12，未提供 M8。代码中的系列校验允许 M8/M12，但这不代表已有可选 M8 物料或已完成 M8 业务验证。
- 连接器与线材的芯数、屏蔽属性须匹配；各连接器加工端须配置外模。
- 双头方案的内模须两端都有或两端都没有。
- 线长为正整数毫米；超过 5 米转人工核价。
- 订单数量范围为 1～1,000,000 的整数。
- 缺少匹配价格、定价参数无效或配置不合规时，不返回正常报价。
- SR 不计材料费与成型费；袋子、纸箱等包装材料不单独计入材料成本，包装人工仍计费。
- 保护套和复杂分支、多线材设计不属于当前自动报价支持范围。

因此，**设计器能够表达的方案范围大于自动报价支持范围**。能完成分支设计，不代表该方案能够自动核价。报价结果仍需结合实际价格、工艺和业务确认使用，不能据此认定全部产品已具备正式报价审批流程。

### 4.4 价格与参数维护

工程师和管理员可维护连接器、线材及模具相关价格，查看价格更新时间与更新人，并通过 Excel 模板导入导出价格表。

定价管理提供材料损耗率、加工损耗率、毛利率、运费率和各工艺单价的编辑，以及 0.5、1、2、3、5 米五档电测、外观、包装人工价格的维护。参数支持 JSON 导入导出，保存带版本检查，新报价使用成功保存后的版本。

## 五、物料库与现有成品方案

### 5.1 物料查询

物料库当前提供连接器、线材、模具与套管、现有成品线束方案四类页面，支持搜索、分类筛选、分页与刷新。

- **连接器**：按名称、型号、编号、供应商编号、系列、芯数、公母类型、屏蔽属性、是否有价格等查询。
- **线材**：按类型、线号、屏蔽属性及价格状态等查询，展示规格与长度价格档位。
- **模具与套管**：查询相关规格及可用价格资料。
- **现有成品方案**：按料号或相关关键词、供应商编号、是否有图纸、是否有成本分析筛选。

该模块以共享资料查询和价格维护为主。当前没有据此确认存在完整的物料主数据增删改后台、供应商业务管理或库存管理；制图工作台另外提供公司辅材新增入口。

### 5.2 成品方案成本分析

对已录入的成品线束，可查看基本资料、供应商编号、已有售价信息和补充二维图纸；具备成本权限及来源数据时，还可查看：

- 材料及加工等成本明细。
- 总成本、售价、样品价、建议对外报价等结果。
- 价格计算步骤、公式表达和推导结果。
- 来源 Excel 在线预览及来源文件信息。
- 一键复制格式化成本与报价推导说明。

没有成本来源表的成品，仅展示当前已有的基础资料。此处主要呈现已录入分析数据，不应理解为已经实现任意 Excel 的通用自动识别核价，或与外部 CRM 的实时双向同步。

## 六、独立制作图纸工作台

该工作台可以独立制作二维线束演示图，无需先创建线束设计器项目。目前该模块及其导出的图纸和物料表仅用于营销展示与功能演示，未投入实际生产使用，不作为加工、领料或生产交付依据。

| 能力 | 当前实现 |
| --- | --- |
| 快速起图 | 配置向导、内置图库模板、端头与线材选配、生成预览 |
| 绘图工具 | 直线、折线、曲线、自由画笔、正交绘制 |
| 工程对象 | 连接器/模型、线材、辅材、文字、序号、图标、号码管、长度标注 |
| 表格 | 接线表、物料表、自定义表格、物料规格文字 |
| 编辑交互 | 选择、移动、缩放、旋转、复制粘贴、删除、图层前后调整、锁定、撤销重做 |
| 资源复用 | 公共物料目录、内置常用语与图标；新增公司辅材并加入当前物料表 |
| 保存与输出 | 登录后的云端保存、草稿恢复、保存冲突处理、PDF 与 XLSX 物料表导出 |

制作图纸入口允许未登录用户使用本地绘图工具、常用语和图标；制图工作区登录使用及云端保存面向工程师和管理员。匿名状态不可访问公共物料目录，也不应视为具有账号级长期存储保障。

独立制作图纸与设计器成品图是两种不同工作流：前者用于营销演示，可独立起图和手工编辑。后者用于表达已有线束项目。当前不应假定两者之间存在完整、自动的双向同步。

## 七、DWG 图纸查看

- 打开本地 DWG 文件，也可选择云端已配置的内置 DWG 图纸。
- 在浏览器内解析并渲染图纸，支持块引用、椭圆、文字、填充、线型、尺寸标注和引线等图元。
- 支持缩放、平移、适配窗口、图层显示隐藏和黑白背景切换。
- 显示图元与图层统计；对跳过的内容和无法加载的外部图片提供提示。
- 导出 PNG 或 A4 横向 PDF，保留所选背景与图层显示状态。

本地 DWG 在浏览器内解析，不会因打开查看自动上传。外部参照图片缺少源文件时仅显示占位框及路径。该模块用于查看与导出，不提供 DWG 原图元编辑或修改后保存 DWG 的功能。

## 八、3D 模型预览与私有保存

### 8.1 文件与查看能力

- 支持 STEP、STP、STL 文件选择或拖入。
- 支持自由旋转、跨上下半球翻转、平移、缩放，以及预设视角、重置和适配窗口。
- 支持浅色/深色背景、无边线/特征边/曲面边界显示，以及全屏查看。
- STEP 提供标准、精细显示质量；STL 支持用户指定毫米、厘米、米或英寸单位。
- 对具备有效 CAD 面映射的模型，可点击高亮完整曲面；STL 或缺少映射的模型按网格选择。
- 展示网格近似包围盒尺寸、三角形数量、网格数量和解析状态。

### 8.2 保存与恢复

原文件仅在用户主动点击保存后上传。系统支持按本人账号保存私有模型、分页查询、重新打开，以及恢复未完成保存；需要重新选择原文件时，会校验文件大小与 SHA-256。

当前文件大小上限为 20 MiB，解析最长 60 秒，解析返回最多接受 1,000,000 个三角形。

此模块属于查看与文件保存能力。包围盒尺寸和边线来自显示网格，属于近似结果；目前没有确认具备参数化实体建模、精确 CAD 测量、装配干涉分析、线束三维布线、AI 建模或从三维模型直接生成报价的功能。

## 九、账号、权限与数据保存

### 9.1 角色分工

| 角色 | 当前主要权限差异 |
| --- | --- |
| 业务员 | 登录后的业务工作区限定为自动报价；获取对外单价和总价，导出对外报价；报价接口不返回内部成本分解 |
| 工程师 | 使用项目设计、物料库、制作图纸、DWG、3D 等完整工作区；查看内部报价明细，导出成本分析，维护价格及定价参数 |
| 管理员 | 具备工程师相关权限，并可分配其他账号角色、重置其他账号密码 |

页面路由会将业务员导向自动报价，内部价格、成本资料及项目、图纸等还受数据库权限控制。项目、独立图纸和私有 3D 模型同时受账号归属限制。真实环境中的权限生效情况仍取决于相关迁移已正确部署。

账号功能包括登录退出、修改本人密码、初始或重置密码强制修改，以及管理员密码重置。新账号创建另有管理脚本，本次未发现前台自助注册入口。

### 9.2 保存与隔离

- **个人数据**：项目、独立制作图纸、私有 3D 模型按账号保存。
- **共享数据**：物料目录、供应商资料、成品方案供登录用户按权限访问；共享价格、定价和内部成本资料按相应权限获取。
- **文档可靠性**：项目和制作图纸有自动保存、本地草稿、保存错误反馈、版本冲突处理及本地副本下载能力。
- **文件访问**：目录图片、成本来源文件、成品图纸、内置 DWG 和私有模型使用相应存储与访问控制。

跨设备继续编辑依赖成功保存到云端。本地草稿受当前浏览器存储条件影响，不能等同于完整离线模式或数据库历史版本。当前未提供多人实时协作、完整文档版本历史与回收站。

## 十、业务流程示例

| 使用场景 | 可采用的现有流程 |
| --- | --- |
| 业务员收到标准 M12 产品询价 | 自动报价页选配两端及线材 → 输入线长数量 → 查看核价 → 导出报价单 |
| 工程师制作分支线束方案 | 新建 T 型或星型项目 → 编辑连接器与 PIN 接线 → 整理保护套和标识 → 导出 BOM、成品图；报价另按支持范围处理 |
